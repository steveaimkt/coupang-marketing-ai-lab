# 쿠팡 광고 분석

> 이 폴더에서 일할 때 클로드 코드가 가장 먼저 읽는 기준입니다. 분석 스킬은 이 기준을 따릅니다.
> 기준을 바꾸려면 이 파일의 「판단 기준」 한 줄을 고칩니다. 스킬이나 코드는 고치지 않습니다.

## 나는 누구인가

쿠팡 광고센터 매출 성장 광고 보고서로 광고 분석기(6개 탭 HTML)를 만들고, 원본과 합계를 맞춰 본 뒤 링크로 나눈다.

**자료 넣는 자리**

```
데이터/{날짜}/        날짜 = 리포트 마지막 날 (2026-10-20 꼴)
  └── A0000…_pa_daily_keyword_….xlsx     받은 이름 그대로
```

분석은 `데이터/` 안에서 **이름이 가장 뒤인 날짜 폴더**의 매출 성장 광고 보고서 하나를 읽는다.

**일하는 순서** · 「쿠팡 광고 분석해줘」 → `coupang-ad-dashboard` 스킬

```
입력 확인 → 분석기 만들기 → 원본과 합계 맞춰 보기 → (사람 확인) → 링크로 나누기
```

## 지표 계산법

- **ROAS = 광고 전환매출 합계 ÷ 광고비 합계 × 100**
- CTR = 클릭 ÷ 노출 × 100 · CPC = 광고비 ÷ 클릭 · CVR = 주문 ÷ 클릭 × 100 · CPA = 광고비 ÷ 주문
- **비율은 합계끼리 나눈다.** 줄마다 낸 비율을 평균하지 않는다
- 전환 기준(1일 또는 14일)은 한 화면에서 하나만 쓴다
- 키워드가 「-」 인 줄(비검색 · 외부 채널)은 합계에는 넣고 키워드 추천에서는 뺀다

## 판단 기준

분석기 생성기(`build.py`)가 아래 줄을 그대로 읽는다. 말로 기준을 바꾸면 이 줄만 고친다.

- attribution_days: 14
- waste_cost_krw: 10000
- star_roas_pct: 300
- potential_roas_pct: 100
- minimum_orders_for_star: 1
- target_roas_pct: null

| 이름 | 뜻 |
|---|---|
| attribution_days | 전환 기준 · 광고를 누른 뒤 며칠 안의 주문까지 칠지 (14 또는 1) |
| waste_cost_krw | 낭비 검토 · 광고비가 이 금액 이상인데 주문이 0건 |
| star_roas_pct | 효자 · ROAS 가 이 % 이상이고 주문이 1건 이상 |
| potential_roas_pct | 가능성 검토 · ROAS 가 이 % 이상, 효자 기준 미만 |
| target_roas_pct | 목표 ROAS · null 이면 목표 달성을 판정하지 않는다 |

숫자로 적는다. 「많이 쓰면」 이 아니라 「1만 원 이상이면」 이다.

## 하지 않는 것

- **원본 엑셀과 파일 이름을 고치지 않는다.** 읽기만 한다. 날짜는 폴더 이름이 맡는다
- **원본과 합계를 맞춰 보기 전에는 결과를 믿지 않는다**
- **사람에게 묻지 않고 분석기를 배포하지 않는다.** 분석기 파일 안에 광고 숫자가 들어 있다
- 내 자료 분석기 링크는 팀 채널에만 나눈다. 공개 게시판에 올리지 않는다
- 실제 쿠팡 광고 계정의 예산 · 입찰 · 키워드는 건드리지 않는다. 분석기는 제안만 한다
- 자료에 없는 숫자나 비교 기간을 지어내지 않는다
