# config · 쿠팡 광고 분석기 직접 만들기

> **실습2에서 여는 유일한 파일입니다.** 다른 파일은 열지 마세요.
> 세 곳을 고치고 저장한 뒤 「config 옮겨서 다시 돌려줘」라고 말하면 됩니다.
> 이 파일은 값을 정하는 메모입니다. 판단 기준은 작업 폴더의 `CLAUDE.md` 에, 제목과 부르는 말은 분석 스킬에
> 클로드 코드가 옮겨 적어야 결과가 바뀝니다.

---

<!-- ⚙️ 개조 포인트 1 · 이 스킬은 무슨 일을 하나 -->
> 여기를 내 업무에 맞게 고치세요.
> 지금 값: 노을뷰티 쿠팡 광고 분석 · 부르는 말 「쿠팡 광고 분석해줘」
> 고치는 법: 분석기 제목에 내 브랜드 이름을 넣고, 부르는 말을 내가 실제로 칠 말로 바꿉니다
> 이걸 바꾸면: 분석기 맨 위 제목과 분석 스킬을 부르는 말이 바뀝니다

```
하는 일 = "쿠팡 매출 성장 광고 보고서로 6개 탭 광고 분석기를 만들고 원본과 합계를 맞춰 본다"
얼마나 자주 = "매주 월요일"
분석기 제목 = "노을뷰티 쿠팡 광고 분석"
부르는 말 = "쿠팡 광고 분석해줘"
```

**부르는 말 정하는 법** · 내가 실제로 쓸 말로 적습니다. 이 말이 분석 스킬의 `description` 에 들어가고, 이 말로 스킬이 불립니다.

⚠️ 폴더 이름(`coupang-ad-dashboard`)은 바꾸지 않습니다. 폴더 이름이 바뀌면 부르는 커맨드가 바뀝니다.

<!-- /개조 포인트 1 -->

---

<!-- ⚙️ 개조 포인트 2 · 무엇을 받아서 시작하나 -->
> 여기를 내 업무에 맞게 고치세요.
> 지금 값: 데이터/ 안 가장 최근 날짜 폴더의 매출 성장 광고 보고서 · 14일 전환
> 고치는 법: 전환 기준을 14 또는 1로 고릅니다. 읽는 자리는 그대로 두고, 새 리포트는 날짜 폴더로 넣습니다
> 이걸 바꾸면: 주문과 매출을 세는 기간이 바뀝니다

```
읽는 자리 = "데이터/*/*pa_daily_keyword*.xlsx"
전환 기준 = "14"
시트 = "자동"
```

**읽는 자리란** · Step 0 에서 만든 `데이터/` 안의 날짜 폴더 중 이름이 가장 뒤인 폴더에서 매출 성장 광고 보고서 하나를 읽는다는 뜻입니다.
폴더 이름은 리포트 마지막 날짜로 짓습니다 (`2026-10-20`). 이름순이 곧 날짜순이라 가장 최근 자료를 틀리지 않고 고릅니다.

**전환 기준이란** · 광고를 누른 뒤 며칠 안의 주문까지 광고 성과로 칠지입니다. 14면 14일, 1이면 그날 하루입니다. 1로 바꾸면 주문과 전환매출이 줄어듭니다.

⚠️ **파일 이름은 바꾸지 마세요.** 광고센터에서 받은 이름(`A0000…_pa_daily_keyword_20261001_20261020.xlsx`) 그대로 넣습니다.
날짜는 폴더 이름이 맡습니다. 지난 자료는 지난 날짜 폴더에 그대로 남습니다.

<!-- /개조 포인트 2 -->

<!-- ⚙️ 개조 포인트 3 · 무엇을 내놓나 -->
> 여기를 내 업무에 맞게 고치세요.
> 지금 값: 낭비 기준 10000원 · 효자 기준 ROAS 300% · 주문 3건 · 마진율 40%
> 고치는 법: 내 상품 단가와 마진에 맞게 금액과 퍼센트를 바꿉니다
> 이걸 바꾸면: 키워드 탭의 낭비 검토·효자 건수, 손익분기 판정과 지면 점검, 실행 계획 탭의 긴급 목록이 바뀝니다

```
낭비 기준 = "10000"
효자 기준 = "300"
효자 최소 주문 = "3"
목표 ROAS = "없음"
마진율 = "40"
키워드 없는 줄 = "추천에서 뺀다"
```

| 값 | 뜻 |
|---|---|
| 낭비 기준 10000 | 14일 동안 광고비가 1만 원 이상인데 주문이 0건이면 낭비 검토로 올린다. 키워드 평균 CPA(주문 1건 받는 데 쓴 광고비)가 약 8,800원이라 1만 원이다 |
| 효자 기준 300 | ROAS가 300% 이상이고 주문이 3건 이상이면 효자로 올린다 |
| 효자 최소 주문 3 | 주문 1~2건은 우연일 수 있어 3건으로 둔다 |
| 목표 ROAS 없음 | 목표를 적지 않으면 목표 달성 여부를 판정하지 않는다 |
| 마진율 40 | 손익분기 ROAS = 100 ÷ 40 × 100 = 250%. ROAS 가 이 값 이상이면 이익, 미만이면 손해로 보고, 지면 ROAS 가 이 값 미만이면 지면 점검에 올린다. 모르면 40, 판정하지 않으려면 「없음」 |
| 키워드 없는 줄 | 키워드가 `-` 인 줄(비검색 영역·외부 채널)은 합계에는 넣고 추천에서는 뺀다 |

**내놓는 자리** · 분석기는 만들 때마다 `결과물/{자료 날짜}_{만든 시각}/` 새 폴더(예 `결과물/2026-10-20_1405/`)에 나옵니다. 고칠 값은 없습니다. 지난 결과물은 덮어쓰지 않으니 개조 전과 후를 나란히 비교할 수 있습니다.

⚠️ **「키워드 없는 줄」을 지우지 마세요.** `-` 줄까지 낭비로 올리면 끌 수 없는 지면을 끄라는 제안이 나옵니다.

<!-- /개조 포인트 3 -->

## 옮겨 적는 자리 (클로드 코드가 합니다)

| 이 파일의 값 | 옮겨 적는 곳 |
|---|---|
| 분석기 제목 | 분석 스킬 config.md 의 `dashboard_title` |
| 부르는 말 | `SKILL.md` 의 `description` |
| 읽는 자리 | 분석 스킬 config.md 의 `input_file` |
| 전환 기준 | **CLAUDE.md** 「판단 기준」 의 `attribution_days` |
| 낭비 기준 | **CLAUDE.md** 「판단 기준」 의 `waste_cost_krw` |
| 효자 기준 | **CLAUDE.md** 「판단 기준」 의 `star_roas_pct` |
| 효자 최소 주문 | **CLAUDE.md** 「판단 기준」 의 `minimum_orders_for_star` |
| 목표 ROAS | **CLAUDE.md** 「판단 기준」 의 `target_roas_pct` (없음이면 `null`) |
| 마진율 | **CLAUDE.md** 「판단 기준」 의 `margin_pct` (없음이면 `null`) |
