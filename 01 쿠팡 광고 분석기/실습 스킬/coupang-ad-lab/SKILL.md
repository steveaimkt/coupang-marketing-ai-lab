## 운영체제를 보고 명령을 바꿔 친다

| | 맥 (터미널) | 윈도우 (파워셸) |

## 이 스킬이 열리는 길

수강생은 이름을 마음대로 정한 빈 폴더에 `coupang-ad-lab.zip` 을 압축을 풀지 않고 넣는다.
클로드 데스크탑 앱 Code 탭에서 그 폴더를 열고 아래 한 줄을 친다.

```
이 폴더의 coupang-ad-lab.zip 을 .claude/skills 에 풀고 쿠팡 광고 분석기 직접 만들기 실습 시작
```

이 한 줄을 받으면 zip 을 `.claude/skills/` 에 푼다. 풀면 `.claude/skills/coupang-ad-lab/` 폴더 하나가 생긴다.
같은 대화에서 그 안의 이 파일을 읽고 아래 시작 화면부터 낸다. 새 세션을 열라고 하지 않는다.
이미 풀려 있으면 다시 풀지 않는다. 풀고 난 zip 은 그대로 둔다.

### 폴더 만들기와 설치 점검

답을 받은 뒤에 만든다. 샘플은 실습 스킬 안 `assets/samples/` 에서 복사한다.

| 답 | 명령 |
|---|---|
| 1 샘플과 함께 | `python3 .claude/skills/coupang-ad-lab/scripts/make_folders.py --workspace .` |
| 2 폴더만 | `python3 .claude/skills/coupang-ad-lab/scripts/make_folders.py --workspace . --no-samples` |

2를 골랐으면 한 줄로 알린다. **"`데이터/` 안에 리포트 마지막 날짜로 폴더(예 2026-10-25)를 만들고 광고센터에서 받은 파일을 이름 그대로 넣어 주세요. Step 1 에서 찾습니다."**

폴더를 만든 뒤 `진행상황.md` 를 만든다. 그다음 **이 실습 전체에서 쓰는 설치 항목을 한 번에 점검한다.** 중간 단계에서 처음 설치하지 않는다.
설치는 클로드가 명령으로 직접 한다. 수강생에게 설치 페이지에서 받으라고 넘기지 않는다. 다만 **묻고 답을 받은 뒤에만** 친다.

먼저 운영체제와 python 이 있는지 본다.

| 운영체제 | 확인 명령 |
|---|---|
| 맥 (터미널) | `python3 --version` |
| 윈도우 (파워셸) | `py --version` (없으면 `python --version`) |

### python 이 없을 때

python 이 없으면 점검 도구도 돌지 않는다. 설치 명령을 먼저 보여 주고 묻는다.

| 운영체제 | 설치 명령 |
|---|---|
| 맥 · Homebrew 있음 (`brew --version` 이 돈다) | `brew install python` |
| 맥 · Homebrew 없음 | Homebrew 설치 한 줄(아래)을 보여 주고 **수강생이 터미널 앱에서 직접** 치게 한다. 맥 로그인 비밀번호를 묻기 때문이다. 클로드는 비밀번호를 받지 않는다. 끝나면 `brew install python` |
| 윈도우 | `winget install -e --id Python.Python.3.12` |

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

이 명령으로 python 을 설치할까요?

⏸

설치가 끝나면 PATH(명령을 찾는 자리 목록)는 새 세션부터 잡힌다. 돌아와서 칠 말 `쿠팡 광고 분석기 직접 만들기 실습 이어서` 를 먼저 알려 주고,
Code 탭에서 새 세션을 열고 같은 폴더를 고르게 한다.

결과물을 보여 주는 로컬 웹(`serve.py`)은 파이썬에 들어 있는 기능이라 따로 설치하지 않는다. playwright 는 선택이다. 없으면 분석기 탭은 눈으로 확인한다.

**마지막 줄 읽는 법**

| 마지막 줄 | 뜻 | 다음 |
|---|---|---|
| 모두 있음 | 설치할 것이 없다 | 바로 마무리 세 줄로 간다 |
| Step 1 진행 가능 · Step 7 전까지 설치: node · npm · netlify-cli | Step 7 배포에만 쓰는 것이 없다 | 설치를 권하고 묻는다. 지금 하지 않으면 Step 1 로 간다 |
| 없는 것 N개 | Step 1~6 에 꼭 필요한 것이 없다 | 설치할지 묻는다. 설치하기 전에는 Step 1 로 가지 않는다 |

| 1 모두 | `python3 .claude/skills/coupang-ad-lab/scripts/check_setup.py --workspace . --install` |
| 2 node 는 나중에 | `python3 .claude/skills/coupang-ad-lab/scripts/check_setup.py --workspace . --install --later-node` |

| 없는 것 | 도구가 치는 명령 |
|---|---|
| openpyxl · PyYAML | 맥 `python3 -m pip install -r requirements.txt` · 윈도우 `py -m pip install -r requirements.txt`. 막히면 작업 폴더 안에 `.venv` 를 만들어 거기에 설치한다 |
| node · npm | 맥 `brew install node` · 윈도우 `winget install -e --id OpenJS.NodeJS.LTS`. 맥에 Homebrew 가 없으면 설치하지 않고 Homebrew 설치 한 줄을 보여 준다 (수강생이 터미널 앱에서 직접 · 비밀번호도 거기서) |
| netlify-cli | `npm install -g netlify-cli`. 권한 문제로 막히면 설치하지 않고 `npx -y netlify-cli` 로 대신 쓴다 |

node 를 방금 설치했으면 PATH 는 새 세션부터 잡힌다. 점검표에 «새 세션부터 바로 쓰임» 이 붙는다. Step 1~6 은 지금 세션에서 그대로 한다.
윈도우 파워셸이 `npm` · `netlify` 를 «스크립트를 실행할 수 없으므로» 로 막으면 `npm.cmd` · `netlify.cmd` 로 바꿔 친다.
그래도 막히면 수강생에게 묻고 답을 받은 뒤 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 친다.

점검표 아래 2줄(파이썬 명령 · 넷리파이 명령)을 `진행상황.md` 맨 위에 적는다. 이어서 할 때도 같은 명령을 쓴다.

```

넷리파이 명령: netlify        (npx -y netlify-cli 로 나오면 Step 7 의 netlify 를 그것으로 바꿔 친다
                               다시 점검할 때는 check_setup.py 끝에 --npx 를 붙인다)

## [4/8] Step 3 · 분석 스킬 만들기 ★ (보통)

## [5/8] Step 4 · 첫 분석기 ★ (김)

수강생이 한마디로 분석 스킬을 부른다.

```

**결과물은 파일로 열지 않고 로컬 웹으로 연다.** 분석 스킬이 만든 뒤 아래 명령으로 연다. 이미 떠 있으면 다시 띄우지 않고 주소만 연다.
포트는 8765 부터 빈 곳을 쓴다. 화면에 주소를 그대로 보여 준다.

```

```

**결과물 폴더 이름** · `{자료 날짜}_{만든 시각}` 입니다. 자료 날짜는 읽은 날짜 폴더 이름(2026-10-20), 시각은 컴퓨터 시각(14시 05분이면 1405)입니다.
만들 때마다 `결과물/` 안에 새 폴더가 생기고, 지난 폴더는 덮어쓰지 않습니다. 같은 분에 또 만들면 `_2` 가 붙습니다.

분석 스킬이 안 잡히면 새 세션을 연다. Code 탭에서 새 세션을 열고 같은 폴더를 고른다. **새 세션을 열기 직전에** 돌아와서 칠 말을 먼저 알려 준다.
`쿠팡 광고 분석기 직접 만들기 실습 이어서` 라고 치시면 Step 4부터 다시 합니다.

1. 파일 이름 · 기간 · 전환 기준 · 지금 무엇을 분석했나
2. 숫자 카드 · 광고비 · 전환매출 · ROAS · 주문, 손익분기 칸 (샘플은 ROAS 241.7% · 손익분기 250% 아래)

4. 키워드 탭 · 낭비 검토 3개 · 효자 5개 · 키워드 평균 CPA 8,781원
5. 실행 계획 탭 · 긴급 · 이번 주 · 이번 달

샘플의 「두피 토닉」 은 효자(한 캠페인)와 낭비 검토(다른 캠페인)에 함께 나옵니다. 분석기는 캠페인별로 따로 세기 때문입니다. 틀린 것이 아닙니다.

**성공 판정** · 탭 6개가 모두 열리고 빈 탭이 없습니다.

탭 6개가 모두 열렸나요? 낭비 검토가 몇 개로 나왔나요?

**먼저 이 순서로 합니다.**

```
1  아래 표에서 증상을 찾는다
2  없으면 오류 메시지를 그대로 붙여 넣고 "이게 안 되는데 왜 그런지 찾아줘"
3  3번 해도 안 되면 받은 01 쿠팡 광고 분석기/ 폴더의 완성예제/ 에서 꺼내 쓰고 다음 단계로 간다
```

| 증상 | 원인 | 대처 |
|---|---|---|
| 시작 한 줄을 쳤는데 zip 을 못 찾는다 | zip 을 다른 폴더에 넣었거나 Code 탭에서 다른 폴더를 열었다 | Code 탭에서 연 폴더 안에 `coupang-ad-lab.zip` 이 있는지 본다 |
| 풀었는데 `.claude/skills/coupang-ad-lab/coupang-ad-lab/` 처럼 한 겹 더 생겼다 | zip 을 스킬 폴더 안에 풀었다 | 안쪽 `coupang-ad-lab/` 을 `.claude/skills/` 바로 아래로 옮겨 달라고 말한다 |
| `실습 스킬이 .claude/skills/ 안에 있어야 합니다` | zip 을 `.claude/skills/` 가 아닌 곳에 풀었다 | 시작 한 줄을 다시 친다. `.claude/skills/coupang-ad-lab/` 이 생겨야 한다 |
| 데이터/ 가 비어 있다 | Step 0 에서 «폴더만» 을 골랐다 | 날짜 폴더를 만들어 내 파일을 넣거나, `샘플도 넣어줘` 라고 말해 Step 0 의 1번 명령을 돌린다 |
| `No module named 'yaml'` 또는 `'openpyxl'` | 파이썬 부품이 없다 | Step 0 의 설치 점검을 다시 돌린다 (`check_setup.py --install`). `.venv` 를 만들었으면 `python3` 대신 `.venv/bin/python` 으로 친다 |
| `python3: command not found` (윈도우 `py` · `python` 을 찾을 수 없음) | 파이썬이 없다 | Step 0 «python 이 없을 때» 의 설치 명령을 보여 주고 묻는다 (맥 `brew install python` · 윈도우 `winget install -e --id Python.Python.3.12`). 끝나면 새 세션에서 이어서 한다 |
| `node: command not found` · 점검표에 «Step 7 전까지 설치» | node 가 없다 | Step 1~6 은 그대로 한다. Step 7 에서 설치하거나 넷리파이 드롭으로 올린다 |
| `brew: command not found` | 맥에 Homebrew 가 없다 | Homebrew 설치 한 줄을 수강생이 터미널 앱에서 직접 친다. 비밀번호도 거기서 넣는다. 끝나면 화면 끝 «Next steps» 줄도 그대로 친 뒤 새 세션에서 다시 점검한다 |
| `winget` 을 찾을 수 없다 | 윈도우에 앱 설치 관리자가 없다 | 마이크로소프트 스토어에서 «앱 설치 관리자» 를 설치한 뒤 다시 점검한다 |
| 관리자 권한이 필요하다 · 설치 창이 승인을 묻는다 | 회사 컴퓨터라 설치가 막혀 있다 | 윈도우는 뜨는 승인 창에서 «예» 를 누른다. 막혀 있으면 회사 IT 담당 부서에 python · node 설치를 요청한다 |
| 설치했는데 `python3` · `node` 를 못 찾는다 | PATH 가 아직 지금 세션에 안 잡혔다 | Code 탭에서 새 세션을 열고 같은 폴더를 고른다. 그래도 안 되면 데스크탑 앱을 완전히 껐다 켠다 |
| 파워셸에서 «스크립트를 실행할 수 없으므로» | 윈도우 실행 정책이 npm · netlify 를 막는다 | `npm.cmd` · `netlify.cmd` 로 바꿔 친다. 또는 묻고 승인을 받은 뒤 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 허용 창에서 실수로 거부했다 | 클로드가 그 명령을 돌리지 못했다 | «다시 해줘» 라고 치고, 이 폴더 안 작업이면 허용한다 |
| "쿠팡 광고 분석해줘" 가 안 잡힌다 | 새로 만든 스킬을 아직 못 읽었다 | `실습 이어서` 문장을 먼저 적어 두고 Code 탭에서 같은 폴더로 새 세션을 연다 |
| `매출 성장 광고 보고서를 찾지 못했습니다` | 파일을 데이터/ 바로 아래에 넣었다 | `데이터/` 안에 날짜 폴더(예 2026-10-25)를 만들고 그 안에 넣는다 |
| `폴더에 매출 성장 광고 보고서가 2개 있습니다` | 같은 날짜 폴더에 두 파일을 넣었다 | 하나만 남기고 다른 하나는 보관/ 으로 옮긴다 |
| 결과물이 어느 폴더인지 모르겠다 | 만들 때마다 새 폴더가 쌓인다 | `결과물/` 안 이름순 마지막 폴더가 가장 최근 결과물이다 |
| 2회차인데 1회차 결과가 나온다 | 새 폴더 이름이 1회차보다 앞 날짜다 | 폴더 이름을 리포트 마지막 날짜로 바꾼다. 이름순으로 가장 뒤 폴더를 읽는다 |
| 3회차에 결과가 그대로다 | 실습 스킬 `config.md` 에만 적었다 | CLAUDE.md 「판단 기준」 줄을 바꿔 달라고 다시 말한다 |
| `CLAUDE.md 가 없습니다` | Step 2 를 건너뛰었다 | Step 2 로 돌아가 CLAUDE.md 부터 만든다 |
| "분석 스킬이 이미 있습니다" | Step 3 을 2번 돌렸다 | 새로 만들지 않는다. 있는 스킬로 Step 4 를 한다 |
| `npm install -g` 에서 `EACCES` 권한 오류 | 전역 설치 자리에 쓸 권한이 없다 | 설치 점검 도구가 `npx -y netlify-cli` 로 대신 씁니다. Step 7 의 `netlify` 를 그것으로 바꿔 칩니다 |
| `netlify: command not found` | 설치를 npx 로 대신했거나 Step 0 을 건너뛰었다 | `진행상황.md` 의 넷리파이 명령을 쓰거나 Step 0 설치 점검을 다시 돌린다 |
| `netlify login` 을 쳤는데 로그인 창이 안 열린다 | 브라우저를 열지 못했다 | `netlify login --request "쿠팡 광고 분석기 배포"` 로 로그인 주소를 받아 브라우저에 직접 붙여 넣고 승인한 뒤, 나온 번호로 `netlify login --check 번호` 를 친다 |
| 사이트 이름이 이미 있다고 나온다 | 넷리파이 전체에서 이름이 겹친다 | 이름 끝에 숫자를 붙여(예 `coupang-ad-hong-1026-2`) `sites:create` 를 다시 친다 |
| 로컬 웹 포트가 쓰이고 있다 | 다른 프로그램이 8765 를 쓴다 | 도구가 다음 포트(8766 …)를 씁니다. 화면에 나온 주소로 엽니다 |
