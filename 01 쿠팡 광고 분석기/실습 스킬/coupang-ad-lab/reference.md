수강생이 받는 것과 실습하는 폴더는 따로다. 받은 폴더를 Code 탭에서 열지 않는다.

```

├── README.md · 프롬프트-툴킷.md
├── coupang-ad-lab.zip                ← 이것만 내 작업 폴더로 옮긴다 (압축은 풀지 않는다)
├── 실습 스킬/coupang-ad-lab/         zip 안에 든 것과 같은 스킬 원본
├── 완성예제/                         분석 스킬 · 분석기 완성본

```

**폴더 만들기** · Step 0 에서 `scripts/make_folders.py --workspace .` 가 `데이터/` · `보관/` · `결과물/` 을 만들고
샘플을 `assets/samples/2026-10-20/` → `데이터/2026-10-20/`, `assets/samples/2026-11-09/` → `보관/2026-11-09/` 로 복사한다.
`--no-samples` 면 폴더만 만든다. `--dry` 면 모양만 보여 준다. 이미 있는 폴더와 파일은 덮어쓰지 않는다.

**설치 점검** · Step 0 에서 `scripts/check_setup.py --workspace .` 가 실습 전체에서 쓰는 것을 표로 찍는다. `--install` 이면 없는 것을 설치한 뒤 다시 찍는다.

| 항목 | 쓰는 곳 | 없으면 |
|---|---|---|
| python3 (3.9 이상) | 모든 도구 | 설치 명령을 보여 주고 묻는다. 맥 `brew install python` · 윈도우 `winget install -e --id Python.Python.3.12` (SKILL.md Step 0 «python 이 없을 때») |
| openpyxl · PyYAML | 엑셀 읽기 · 설정 읽기 (`requirements.txt`) | `pip` 로 설치. 막히면 작업 폴더 안 `.venv` 에 설치 |
| node · npm | 넷리파이 CLI (Step 7 에만) | 「Step 7 전까지 설치」 로 보이고 Step 1 은 진행한다. 맥 `brew install node` · 윈도우 `winget install -e --id OpenJS.NodeJS.LTS`. 설치가 막히면 Step 7 은 넷리파이 드롭(app.netlify.com/drop)으로 올린다 |
| netlify-cli | Step 7 배포 | `npm install -g netlify-cli`. 막히면 `npx -y netlify-cli` 로 대신 |
| playwright (선택) | `verify-browser.cjs` 탭 자동 확인 | 설치하지 않는다. 없어도 실습은 된다. 탭은 눈으로 본다 |

로컬 웹(`serve.py`)은 파이썬 내장 `http.server` 를 쓴다. 따로 설치할 것이 없다.

**결과물 보기** · 결과물은 파일로 열지 않고 로컬 웹으로 연다.
`python3 .claude/skills/coupang-ad-dashboard/assets/dashboard/serve.py --workspace .` 가 `결과물/` 을 뿌리로 띄우고 가장 최근 폴더 주소를 연다.
포트는 8765 부터 빈 곳을 쓴다. 이미 떠 있으면 다시 띄우지 않는다. `--dir 폴더이름` 은 그 폴더, `--list` 는 쌓인 폴더 목록(`http://localhost:{포트}/`), `--stop` 은 끄기다.
화면을 저장하지 않게 보내므로 다시 만든 뒤에는 새로고침만 하면 된다. 브라우저 확인(`verify-browser.cjs`)도 로컬 웹이 떠 있으면 같은 주소로 연다.

**읽는 규칙** · `데이터/` 안 날짜 폴더 중 이름이 가장 뒤인 폴더의 `*pa_daily_keyword*.xlsx` 하나를 읽는다.
같은 폴더에 둘이 있으면 멈추고 묻는다. 없으면 날짜 폴더를 만들라고 알린다.

**내놓는 규칙** · 분석기를 만들 때마다 `결과물/{자료 날짜}_{만든 시각 HHMM}/` 새 폴더에 넣는다. 지난 폴더는 덮어쓰지 않는다.
자료 날짜는 읽은 날짜 폴더 이름(`2026-10-20`), 시각은 컴퓨터 현지 시각이다. 같은 이름이 있으면 `_2`, `_3` 을 붙인다.
**가장 최근 결과물**은 `결과물/` 안 폴더 이름순 마지막이다. 원본 대조(`verify.py`), 브라우저 확인(`verify-browser.cjs`), 배포는 따로 말이 없으면 이 폴더를 쓴다.
지난 결과물을 맞춰 볼 때는 `verify.py` 에 `--dir 2026-10-20_1405` 처럼 폴더 이름을 붙인다.

## 출력 스키마

분석기는 탭 6개다. 이름과 순서는 분석 스킬 `config.md` 의 `menu_items` 를 따른다.

| 탭 | 들어가는 것 |
|---|---|
| 대시보드 | 요약 문장, 광고비·전환매출·ROAS·주문·CTR·CPC·CVR·CPA 카드, 일별 광고비와 매출 차트, 캠페인 ROAS 상위 5 |
| 일별 | 날짜순 광고비·매출·ROAS, 노출 → 클릭 → 주문 단계별 수치 |
| 지면 | 검색 영역 · 비검색 영역 · 외부 채널별 광고비·매출·ROAS·광고비 비중 |
| 키워드 | 낭비 검토·효자 건수, 검색창, 정렬되는 성과표 |
| 인사이트 | 주문 없는 지출, 고효율 키워드, 지면 비교, 클릭 대비 주문 |
| 실행 계획 | 긴급 · 이번 주 · 이번 달로 나눈 제안과 근거 숫자 |

계산은 합계로 한다. ROAS = 전환매출 합계 ÷ 광고비 합계 × 100. 줄마다 ROAS를 낸 뒤 평균하지 않는다.

## 판단 기준

| 분류 | 기준 (기본값) | 바꾸는 곳 |
|---|---|---|
| 낭비 검토 | 광고비 10,000원 이상 · 주문 0건 | CLAUDE.md `waste_cost_krw` |
| 효자 | ROAS 300% 이상 · 주문 3건 이상 | CLAUDE.md `star_roas_pct` · `minimum_orders_for_star` |
| 가능성 검토 | 주문은 있는데 ROAS 100% 미만 | CLAUDE.md `potential_roas_pct` |
| 손익분기 | 마진율 40% → 손익분기 ROAS 250%. ROAS 가 이 값 이상이면 이익, 미만이면 손해 | CLAUDE.md `margin_pct` (null 이면 판정 안 함) |
| 지면 점검 | 지면 ROAS 가 손익분기 미만 | `margin_pct` 를 따라간다 |
| 키워드 미지정 | 키워드가 `-` 인 줄 | 합계에는 넣고 추천에서는 뺀다. 지면 점검에서는 지면 광고비로 함께 본다 |

**기본값의 근거**

| 값 | 왜 이 숫자인가 |
|---|---|
| 낭비 10,000원 | 키워드 평균 CPA(주문 1건 받는 데 쓴 광고비)만큼 쓰고도 주문이 0건이면 낭비로 본다. 샘플 1회차 키워드 평균 CPA가 8,781원(키워드 미지정 제외)이라 약 8,800원, 그래서 1만 원 |
| 효자 주문 3건 | 주문 1~2건은 우연일 수 있다. 3건 이상이어야 다시 일어날 일로 본다 |
| 마진율 40% | 모르면 40으로 둔다. 손익분기 ROAS = 100 ÷ 마진율 × 100 = 250% |
| 지면 점검 | 키워드가 없는 비검색 영역 · 외부 채널 광고비는 키워드 분류에서 빠진다. 지면 ROAS 로 이 광고비를 함께 본다 |

Step 2 에서 전환 기준 · 낭비 기준 · 효자 기준 · 목표 ROAS · 마진율 · 지면 점검 6가지를 기본값과 함께 묻고, 답을 받은 뒤 그대로 CLAUDE.md 를 만든다.
묻지 않고 기본값으로 만들지 않는다. 샘플 정답은 기본값(전환 14일 · 낭비 1만 원 · 효자 300% · 주문 3건 · 목표 없음 · 마진율 40) 기준이다.

숫자로 적는다. "많으면" 이 아니라 "1만 원 이상이면" 이라고 적는다.
**금칙어** · 전반적으로 · 대체로 · 양호한 · 개선이 필요한. 이런 말이 나오면 기준이 비어 있다는 뜻이다.

## 샘플 정답

가상 브랜드 「노을뷰티」. 실제 쿠팡 매출 성장 광고 보고서를 고쳐 만들었다. 브랜드 · 상품 · 캠페인 · 검색어 · ID 는 가짜이고 칸 44개는 같다.

| | 1회차 `데이터/2026-10-20/` | 2회차 `보관/2026-11-09/` → `데이터/` |
|---|---|---|
| 기간 | 2026-10-01~2026-10-20 | 2026-10-21~2026-11-09 |
| 행 수 | 2,231 | 2,534 |
| 광고비 | 1,861,592원 | 4,870,594원 |
| 전환매출 (14일) | 4,498,990원 | 13,934,360원 |
| 주문 (14일) | 184건 | 522건 |
| ROAS | 241.7% | 286.1% |
| 검색 키워드 (「-」 제외) | 80개 | 110개 |
| 키워드 평균 CPA (키워드 미지정 제외) | 8,781원 | 8,412원 |
| 손익분기 (마진율 40 · 250%) | 아래 | 위 |
| 지면 점검 | 2곳 · 비검색 영역 225.5% · 외부 채널 220.3% (광고비 1,167,869원) | 0곳 |
| 효자 (300% · 주문 3건) | 5개 | 12개 |
| 낭비 검토 (1만 원) | 3개 · 두피 토닉 40,629원 · 노을뷰티 15,511원 · 탄력 마스크팩 12,333원 | 6개 · 미백 앰플 22,105원 · 1일1팩 15,667원 · 붙이는 팩 13,880원 · 수분 앰플 12,956원 · 노을뷰티 손상모 오일 11,101원 · 주름 앰플 10,960원 |
| 낭비 검토 (2만 원) | 1개 · 두피 토닉 | 1개 · 미백 앰플 |

낭비 검토와 효자는 「캠페인 + 광고그룹 + 지면 + 키워드」 묶음 하나를 한 항목으로 센다. 같은 키워드라도 캠페인이 다르면 따로 센다.
그래서 1회차 「두피 토닉」 은 효자(한 캠페인 · 주문 4건 · ROAS 1076.1%)와 낭비 검토(다른 캠페인 · 40,629원 · 주문 0건)에 함께 나온다. 틀린 것이 아니다.

## 3회 구동

같은 스킬을 세 번 돌려 도구인지 확인하는 절차다.

| 회차 | 무엇을 바꾸나 | 무엇을 보나 | 샘플이면 |
|---|---|---|---|
| 1회차 | 아무것도 (기본) | 일단 도는가 | 광고비 1,861,592원 · ROAS 241.7% · 손익분기 아래 · 효자 5개 · 낭비 검토 3개 · 지면 점검 2곳 |
| 2회차 | 자료만 교체 | 스킬을 안 고쳐도 도는가 | 광고비 4,870,594원 · ROAS 286.1% · 손익분기 위 · 효자 12개 · 낭비 검토 6개 · 지면 점검 0곳 |
| 3회차 | 낭비 기준만 변경 (1만 원 → 2만 원) | 기준이 결과를 바꾸는가 | 낭비 검토 1개 (미백 앰플 22,105원) · 나머지는 2회차와 같다 |

세 번 다 돌면 도구다. 한 번만 도는 것은 대화이지 도구가 아니다.

**2회차에 하는 것은 `데이터/` 에 새 날짜 폴더를 넣는 것뿐이다.** 스킬 폴더 안의 파일은 하나도 고치지 않는다. 1회차 폴더도 지우지 않는다.
**3회차에 바꾸는 것은 CLAUDE.md 「판단 기준」 의 `waste_cost_krw` 한 줄뿐이다.** 스킬 파일은 2·3회차 내내 그대로다.
**3회차까지 돌고 나면 `결과물/` 안에 폴더가 3개 있다.** 회차마다 새 폴더에 쌓이고, 앞 회차 폴더는 그대로 남는다.

## 배포

넷리파이 CLI(명령으로 올리는 도구)를 쓴다. 설치는 Step 0 에서 끝냈다. Step 7 에서는 로그인과 배포만 한다.
명령과 옵션은 netlify-cli 27.14.2 의 `--help` 로 확인했다. 점검표에 「npx 로 대신」 이 나왔으면 `netlify` 를 `npx -y netlify-cli` 로 바꿔 친다.

| 순서 | 명령 | 하는 일 |
|---|---|---|
| 1 | `netlify status` | 로그인돼 있는지 본다 |
| 2 | `netlify login` | 브라우저가 열린다. 수강생이 직접 로그인하고 Authorize 를 누른다 |
| 3 | (복사) | 가장 최근 결과물에서 세 파일만 `배포용/` 에 복사한다 |
| 4 | 사람에게 묻는다 | 샘플 · 내 자료 · 올리지 않음 중 고른다 |
| 5 처음 | `netlify sites:create --name 이름` | 사이트를 만들고 이 폴더를 연결한다. `.netlify/state.json` 이 생긴다 |
| 5 처음 · 다음부터 | `netlify deploy --dir 배포용 --prod --no-build` | `배포용/` 을 연결된 사이트에 올린다. 주소는 그대로다 |

| 지킬 것 | 왜 |
|---|---|
| 올리기 전에 사람에게 묻는다 | 분석기 `script.js` 안에 광고 숫자가 그대로 들어 있다. 링크를 아는 사람은 누구나 본다 |
| 비밀번호와 토큰을 받지 않는다 | 로그인은 수강생이 브라우저에서 직접 한다. `--auth` 옵션에 토큰을 넣지 않는다 |
| 가장 최근 결과물에서 세 파일만 `배포용/` 에 복사한다 | 결과물 폴더의 검증 기록(`검증결과.md` · `검산.json`)은 보는 사람에게 필요 없다 |
| `배포용/` 은 `결과물/` 밖에 둔다 | `결과물/` 안에는 분석기 폴더만 쌓아야 이름순 마지막이 곧 가장 최근 결과물이다 |
| `--prod` 를 붙인다 | 빼면 임시 주소(draft)로만 올라간다 |
| `--no-build` 를 붙인다 | 만들 것이 없는 화면 파일 세 개라 빌드를 건너뛴다 |
| `.netlify/` 폴더를 밖으로 올리지 않는다 | 이 컴퓨터와 사이트를 잇는 정보(`state.json`)가 들어 있다. 다음 배포 때 같은 사이트를 찾는 데 쓴다 |
| 내 자료 분석기 링크는 팀 안에서만 나눈다 | 단톡방 · 공개 게시판에 올리지 않는다 |

**사이트 이름** · 영문 소문자 · 숫자 · `-` 만 쓴다. 넷리파이 전체에서 겹치면 안 되므로 이름이나 날짜를 붙인다 (예 `coupang-ad-hong-1026`).
**팀을 고르라고 물을 때** · 계정에 팀이 둘 이상이면 `sites:create` 가 묻는다. 멈추고 수강생에게 팀 이름을 받아 `--account-slug 팀이름` 을 붙인다.
**로그인 창이 안 열릴 때** · `netlify login --request "쿠팡 광고 분석기 배포"` 가 로그인 주소와 번호를 준다. 수강생이 주소를 브라우저에 붙여 넣고 승인한 뒤 `netlify login --check 번호` 를 친다.

## 자주 나오는 질문

**코딩을 몰라도 되나요**
됩니다. 수강생은 한국어로 말하고, 나온 화면이 맞는지만 봅니다. 명령은 클로드 코드가 칩니다.

**광고센터 파일 이름을 그대로 써도 되나요**
됩니다. 이름은 그대로 두고 `데이터/` 안에 리포트 마지막 날짜로 폴더(예 `2026-10-25`)를 만들어 넣습니다. 분석기는 가장 최근 날짜 폴더를 읽습니다.

**분석기가 광고를 꺼 주나요**
아닙니다. 분석기는 제안만 합니다. 실제 키워드를 끄거나 입찰을 바꾸는 일은 광고센터에서 사람이 합니다.

## 에러 대응

| 에러 | 무슨 뜻 | 어떻게 |
|---|---|---|
| `ModuleNotFoundError: No module named 'yaml'` | PyYAML이 없다 | Step 0 설치 점검을 다시 돌린다 · `check_setup.py --workspace . --install` |
| `시트를 선택해 sheet_name에 저장하세요` | 엑셀에 시트가 여러 개다 | 보이는 시트 이름 중 하나를 골라 분석 스킬 `config.md` 의 `sheet_name` 에 적는다 |
| `필수 열 누락: [...]` | 매출 성장 광고 보고서가 아닌 파일을 넣었거나 칸이 빠졌다 | 광고센터 > 광고 보고서 > 매출 성장 광고 보고서로 받은 파일인지 본다 |
| `CLAUDE.md 가 없습니다` | Step 2 를 건너뛰었다 | `scripts/claude_md.py` 로 먼저 만든다 |
| `설정과 화면이 일치하지 않습니다` | 기준을 바꾼 뒤 분석기를 다시 안 만들었다 | "쿠팡 광고 분석해줘" 로 다시 만든 뒤 맞춰 본다 |
| `가장 최근 결과물(...)이 지금 자료로 만든 것이 아닙니다` | 새 날짜 폴더를 넣고 분석기를 다시 안 만들었다 | "쿠팡 광고 분석해줘" 로 다시 만든 뒤 맞춰 본다. 지난 결과물이면 `--dir 폴더이름` 을 붙인다 |
| `결과물이 아직 없습니다` | Step 4 를 건너뛰었다 | "쿠팡 광고 분석해줘" 로 분석기부터 만든다 |
| `분석 스킬이 이미 있습니다` | Step 3 을 2번 돌렸다 | 새로 만들지 않고 있는 스킬로 계속한다 |
| `config.md는 작업폴더/.claude/skills/스킬이름 안에 있어야 합니다` | 내 작업 폴더가 아닌 폴더를 Code 탭에서 열었다 | `데이터/` 와 `.claude/` 가 보이는 내 작업 폴더를 열고 다시 한다 |
| `실습 스킬이 .claude/skills/ 안에 있어야 합니다` | zip 을 `.claude/skills/` 가 아닌 곳에 풀었다 | 시작 한 줄을 다시 친다. 풀면 `.claude/skills/coupang-ad-lab/` 이 생겨야 한다 |
| `매출 성장 광고 보고서를 찾지 못했습니다` | 파일을 데이터/ 바로 아래에 넣었다 | 날짜 폴더를 만들고 그 안에 넣는다 |
| `폴더에 매출 성장 광고 보고서가 2개 있습니다` | 같은 날짜 폴더에 두 파일 | 하나만 남긴다 |
| `npm ERR! code EACCES` | 전역 설치 권한이 없다 | `npx -y netlify-cli` 로 대신 쓴다 (설치 점검 도구가 알아서 바꾼다) |
| `Not logged in` | 넷리파이에 로그인하지 않았다 | `netlify login` · 수강생이 브라우저에서 승인한다 |
| 사이트 이름이 이미 있다 | 이름이 겹친다 | 끝에 숫자를 붙여 `sites:create` 를 다시 친다 |
| `포트가 모두 쓰이고 있습니다` | 8765~8800 이 다 쓰인다 | 쓰지 않는 프로그램을 닫고 다시 연다 |
