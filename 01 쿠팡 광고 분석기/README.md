# 01 쿠팡 광고 분석기

> 5교시 「쿠팡 광고 분석기 직접 만들기 실습」 자료입니다.
> CLAUDE.md 로 기준을 먼저 잡고, 쿠팡 매출 성장 광고 보고서로 6개 탭 광고 분석기를 만들어 그 순서를 분석 스킬로 남긴 뒤 링크로 나눕니다.
> **코드를 고치지 않습니다.** 한국어로 말하고, 나온 화면이 맞는지 판단합니다.

## 결과물

1. CLAUDE.md (이 폴더의 기준 · 제목 4개)
2. 다음 주에도 한마디로 다시 쓰는 분석 스킬 한 벌 (`coupang-ad-dashboard`)
3. 링크로 나누는 쿠팡 광고 분석기 1개
4. 3회 구동 기록 (`결과물/3회구동.md`)

## 안에 든 것

```
01 쿠팡 광고 분석기/
├── README.md               지금 읽는 파일
├── 프롬프트-툴킷.md         참고용 요청 예시와 실습에서 쓰는 한마디
├── coupang-ad-lab.zip      ← 이것을 내 작업 폴더에 넣는다 (압축은 풀지 않는다)
├── 실습 스킬/coupang-ad-lab/   zip 안에 든 실습 스킬 원본 (열어 보기용)
│   ├── SKILL.md · config.md · reference.md
│   ├── scripts/            폴더 만들기 · 설치 점검 · CLAUDE.md 만들기 · 분석 스킬 설치
│   ├── assets/             분석기 생성기 · 화면 · 검증기 · 로컬 웹
│   │   └── samples/        샘플 매출 성장 광고 보고서 2회차분 (Step 0 이 작업 폴더로 복사한다)
│   └── requirements.txt    파이썬 부품 2개
├── 완성예제/                ← 실습으로 만들어지는 것의 완성본
│   ├── CLAUDE.md
│   ├── .claude/skills/coupang-ad-dashboard/
│   └── 결과물/2026-10-20_0711/
```

`.claude` 폴더는 맥 Finder 에서 숨김 폴더라 안 보일 수 있습니다. `Command + Shift + .` 을 누르면 보입니다.

## 준비물

- 클로드 데스크탑 앱 (유료 요금제) · 터미널을 열지 않습니다
- python3 와 node · 없으면 Step 0 에서 클로드가 설치 명령(맥 터미널 · 윈도우 파워셸)을 보여 주고, 답을 받은 뒤 설치합니다
- node 는 Step 7 배포에만 씁니다. 없어도 Step 1~6 은 진행하고, Step 7 전까지 설치합니다 (설치가 막히면 넷리파이 드롭으로 올립니다)
- 나머지(파이썬 부품 2개 · 넷리파이 CLI)는 Step 0 의 설치 점검표를 보고 클로드가 한 번에 설치합니다
- 넷리파이 무료 계정 · Step 7 에서 브라우저로 직접 로그인합니다

> **윈도우라면**
> 클로드가 운영체제를 보고 명령을 바꿔 칩니다. 설치 명령은 파워셸로 칩니다.
>
> | | 맥 | 윈도우 |
> |---|---|---|
> | 파이썬 | `python3` | `py` (없으면 `python`) |
> | .venv 파이썬 | `.venv/bin/python` | `.venv\Scripts\python` |
> | 넷리파이 | `netlify` | `netlify` (파워셸이 스크립트 실행을 막으면 `netlify.cmd`) |
> | 새로고침 | Command + R | Ctrl + R |
> | 숨김 폴더 `.claude` 보기 | Finder 에서 Command + Shift + . | 파일 탐색기 > 보기 > 숨긴 항목 |

## 걸리는 시간

영상 25분 · 직접 하시면 1시간 안팎입니다.
최소선(Step 5 원본과 맞춰 보기까지)만 하면 30분입니다. 4-2 보고 고치기와 실습2 는 선택입니다.

## 회사 자료

내 광고 보고서를 쓰시려면 회사 보안 규칙에서 클로드에 올려도 되는 자료인지 먼저 확인하세요. 샘플만으로도 실습을 끝까지 할 수 있습니다.

## 시작하는 법

1. 바탕화면에 폴더를 하나 만듭니다. 이름은 마음대로 정합니다 (예 `내쿠팡실습`)
2. 이 폴더의 `coupang-ad-lab.zip` 을 그 폴더 안에 넣습니다. **압축은 풀지 않습니다**
3. 클로드 데스크탑 앱 위쪽의 **Code** 탭을 열고, 방금 만든 폴더를 고릅니다
4. 아래 한 줄을 칩니다

```text
이 폴더의 coupang-ad-lab.zip 을 .claude/skills 에 풀고 쿠팡 광고 분석기 직접 만들기 실습 시작
```

클로드가 zip 을 이 폴더 안 `.claude/skills/` 에 풀고, 같은 대화에서 바로 실습 시작 화면을 보여 줍니다.
파일을 쓰거나 명령을 돌릴 때 허용을 묻는 창이 뜹니다. 이 폴더 안 작업이면 허용하세요. 실수로 거부했으면 «다시 해줘» 라고 치시면 됩니다.

Step 0 에서는 먼저 만들 폴더 모양을 보여 주고 묻습니다. 답하면 이 모양으로 만들고 샘플을 넣습니다.

```
내쿠팡실습/
├── 데이터/2026-10-20/   원본 · 읽기만 · 샘플 1회차 파일
├── 보관/2026-11-09/     2회차 샘플 (3회 구동 때 데이터/ 로 옮긴다)
├── 결과물/              만들 때마다 날짜_시각 폴더가 쌓인다
└── .claude/skills/      실습 스킬
```

그다음 설치 점검표를 보여 주고, 없는 것이 있으면 설치할지 묻습니다. 점검표가 「모두 있음」 이나 「Step 1 진행 가능」 이 되면 Step 1 로 갑니다.
쉬었다가 돌아오면 같은 폴더를 Code 탭에서 열고 `쿠팡 광고 분석기 직접 만들기 실습 이어서` 라고 치세요.

## 완성 예제 먼저 보기

완성예제를 로컬 웹으로 엽니다. Code 탭에서 이 `01 쿠팡 광고 분석기/` 폴더를 열고 이렇게 치세요.

```text
완성예제/결과물 폴더를 python3 -m http.server 로 띄우고 2026-10-20_0711 폴더를 브라우저로 열어줘
```

`http://localhost:8000/2026-10-20_0711/` 처럼 주소가 열립니다. 다 보면 「로컬 웹 꺼줘」 라고 하세요.
실습 중에는 분석 스킬의 로컬 웹 도구가 `http://localhost:8765/{폴더}/` 로 결과물을 엽니다.
폴더 이름은 `{자료 날짜}_{만든 시각}` 입니다. 실습에서도 분석기를 만들 때마다 `결과물/` 안에 이런 폴더가 하나씩 쌓이고, 지난 폴더는 덮어쓰지 않습니다.

- 샘플 · 가상 브랜드 「노을뷰티」 매출 성장 광고 보고서 · 2026-10-01~10-20 · 14일 전환
- 광고비 1,861,592원 · 전환매출 4,498,990원 · 주문 184건 · ROAS 241.7%
- 손익분기 · 마진율 40% → 손익분기 ROAS 250% · 지금 ROAS 가 그 **아래** · 지면 점검 2곳 (비검색 영역 · 외부 채널)
- 탭 · 대시보드 → 일별 → 지면 → 키워드 → 인사이트 → 실행 계획
- 낭비 검토 3개 (기준 1만 원) · 두피 토닉 · 노을뷰티 · 탄력 마스크팩
- 효자 5개 (ROAS 300% · 주문 3건 이상) · 두피 토닉 · 23호 쿠션 · 세안제 추천 · 건성 쿠션 · 선쿠션
- 「두피 토닉」 은 효자와 낭비 검토에 함께 나옵니다. 분석기가 캠페인별로 따로 세기 때문입니다

## 여덟 단계

| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| Step 0 폴더 만들기와 준비 확인 | 폴더 모양을 보고 만든 뒤 설치 점검표대로 한 번에 설치 | 폴더 3개 · 점검표 「모두 있음」 또는 「Step 1 진행 가능」 |
| Step 1 입력 확인 | 데이터/ 의 가장 최근 날짜 폴더에서 리포트를 연다 | 칸 44개 · 2,231행 · 10/01~10/20 |
| Step 2 CLAUDE.md 만들기 | 판단 기준 6가지를 묻고 답대로 만든다 (기본 전환 14일 · 낭비 1만 원 · 효자 ROAS 300% · 주문 3건 · 목표 없음 · 마진율 40 · 지면 점검) | 제목 4개 · 판단 기준 줄 |
| Step 3 분석 스킬 만들기 | coupang-ad-dashboard 만들기 | 파일 셋이 생긴다 |
| Step 4 첫 분석기 | 「쿠팡 광고 분석해줘」 · 로컬 웹으로 연다 | 탭 6개 · 낭비 검토 3개 · 효자 5개 · 손익분기 아래 · 지면 점검 2곳 |
| 4-2 보고 고치기 | 색 · 탭 순서 · 표 칸 · 차트 중 하나를 분석 스킬에서 고치고 다시 만든다 | 새 폴더에서 바뀐 모양 · 숫자는 그대로 |
| Step 5 원본과 맞춰 보기 | 「원본 엑셀과 분석기 합계를 맞춰 봐줘」 | 1,861,592원 · 4,498,990원 · 184건 · 판정도 같음 |
| Step 6 3회 구동 | 자료만 바꾸고, CLAUDE.md 기준만 바꿔 다시 | 낭비 검토 3 → 6 → 1 · 손익분기 아래 → 위 · 결과물 폴더 3개 (4-2 를 했으면 4개) |
| Step 7 링크로 나누기 | 넷리파이에 로그인하고 가장 최근 결과물을 넷리파이 CLI 로 올린다 | 링크가 다른 브라우저에서 열린다 |

**Step 4 첫 분석기와 Step 5 원본과 맞춰 보기는 건너뛰지 마세요.** 이 둘이 없으면 결과물이 남지 않습니다.

## 내 리포트로 할 때

### 내 쿠팡 파일 받는 순서

1. 광고센터 > 광고 보고서 > 매출 성장 광고 보고서를 엽니다
2. 기간을 **7일 이상**으로 고릅니다
3. 보고서는 **키워드 단위 · 일별**로 고릅니다
4. 파일 형식은 **.xlsx** 로 받습니다
5. Step 0 에서 «샘플 없이 폴더만» 을 고르고, `데이터/` 안에 폴더를 만듭니다. 폴더 이름은 **기간의 끝 날짜**입니다 (예 10/01~10/25 이면 `2026-10-25`)
6. 받은 파일을 **받은 이름 그대로** 그 폴더에 넣습니다. 파일 이름을 바꾸지 않습니다
7. Step 1 에서 2번(내 광고 보고서)을 고르고 브랜드 이름을 알려 주면 분석기 제목이 «{브랜드} 쿠팡 광고 분석» 이 됩니다

**기간이 7일보다 짧으면** 키워드마다 광고비와 주문이 적어 낭비 검토 · 효자가 거의 나오지 않을 수 있습니다. 7일 이상 받으세요.
분석기는 이름이 가장 뒤인 날짜 폴더를 읽습니다. 지난 자료는 지난 폴더에 그대로 남습니다.

## 자주 나오는 질문

**시작 한 줄을 쳤는데 zip 을 못 찾아요**
Code 탭에서 연 폴더 안에 `coupang-ad-lab.zip` 이 있는지 보세요. 받은 `01 쿠팡 광고 분석기/` 폴더가 아니라 내가 만든 작업 폴더를 열어야 합니다.

**다시 만들었는데 화면이 그대로예요**
주소 끝 폴더 이름이 가장 최근 폴더인지 보고 새로고침(Command + R)하세요.

**분석기 모양을 고쳤는데 다음 주에 원래대로 돌아갔어요**
결과물 폴더의 파일을 직접 고치면 다음에 만들 때 사라집니다. 4-2 처럼 「스킬에 반영해서 다음에도 남게 해줘」 라고 말하세요.

**분석기 링크를 아무에게나 보내도 되나요**
안 됩니다. 분석기 파일 안에 광고 숫자가 들어 있어 링크를 아는 사람은 누구나 봅니다. 내 자료 분석기는 팀 채널에만 나누세요.

**분석기가 광고를 꺼 주나요**
아닙니다. 제안만 합니다. 키워드를 끄거나 입찰을 바꾸는 일은 광고센터에서 사람이 합니다.

**샘플 자료는 진짜 회사 자료인가요**
아닙니다. 실제 쿠팡 매출 성장 광고 보고서를 고쳐 만든 가상 브랜드 「노을뷰티」 자료입니다. 브랜드 · 상품 · 캠페인 · 검색어 · ID 를 모두 가짜로 바꾸고 금액도 바꿨습니다. 칸 44개와 값 형식은 실제 보고서와 같습니다.
