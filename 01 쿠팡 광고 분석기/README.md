# 01 쿠팡 광고 분석기

> 5교시 「쿠팡 광고 분석기 직접 만들기 실습」 자료입니다.
> CLAUDE.md 로 기준을 먼저 잡고, 쿠팡 매출 성장 광고 보고서로 6개 탭 광고 분석기를 만들어 그 순서를 분석 스킬로 남긴 뒤 링크로 나눕니다.
> **코드를 고치지 않습니다.** 한국어로 말하고, 나온 화면이 맞는지 판단합니다.

## 결과물

1. CLAUDE.md (이 폴더의 기준 · 제목 4개)
2. 다음 주에도 한마디로 다시 쓰는 분석 스킬 한 벌 (`coupang-ad-dashboard`)
3. 링크로 나누는 쿠팡 광고 분석기 1개
4. 3회 구동 기록 (`결과물/3회구동.md`)

## 안에 든 것

```

├── 실습자료/                ← 클로드 데스크탑 앱 Code 탭에서 이 폴더를 연다
│   ├── .claude/skills/coupang-ad-lab/   실습을 한 단계씩 안내하는 실습 스킬

│   │   ├── scripts/setup.py             분석 스킬 설치 도구
```

`.claude` 폴더는 맥 Finder 에서 숨김 폴더라 안 보일 수 있습니다. `Command + Shift + .` 을 누르면 보입니다.

## 시작하는 법

준비물은 클로드 데스크탑 앱 하나입니다 (유료 요금제). 터미널을 열지 않습니다.

1. 노션 실습 페이지에서 zip 을 받아 **압축을 풉니다.** 압축을 안 풀면 열리지 않습니다
2. 클로드 데스크탑 앱 위쪽의 **Code** 탭을 엽니다
3. 폴더 고르기에서 `01 쿠팡 광고 분석기/실습자료` 폴더를 **통째로** 고릅니다. 파일 하나만 고르면 안 됩니다
4. 아래 한마디를 칩니다

```text
쿠팡 광고 분석기 직접 만들기 실습 시작
```

실습 스킬이 시작 화면을 보여 주고 Step 0 부터 한 단계씩 묻습니다. 쉬었다가 돌아오면 `쿠팡 광고 분석기 직접 만들기 실습 이어서` 라고 치세요.

## 완성 예제 먼저 보기

`완성예제/결과물/2026-10-20_0607/index.html` 을 브라우저에서 엽니다. 세 파일(index.html · styles.css · script.js)이 한 폴더에 있어야 합니다.
폴더 이름은 `{자료 날짜}_{만든 시각}` 입니다. 실습에서도 분석기를 만들 때마다 `결과물/` 안에 이런 폴더가 하나씩 쌓이고, 지난 폴더는 덮어쓰지 않습니다.

- 샘플 · 가상 브랜드 「노을뷰티」 매출 성장 광고 보고서 · 2026-10-01~10-20 · 14일 전환
- 광고비 1,793,660원 · 전환매출 4,293,160원 · 주문 173건 · ROAS 239.4%
- 탭 · 대시보드 → 일별 → 지면 → 키워드 → 인사이트 → 실행 계획
- 낭비 검토 3개 (기준 1만 원) · 노을뷰티 약산성 샴푸 · 노을뷰티 헤어 오일 · 진정 마스크팩

## 여덟 단계

| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| Step 0 준비 확인 | 파이썬 부품 2개 설치 | 「부품 2개 준비됨」 |
| Step 1 입력 확인 | 데이터/ 의 가장 최근 날짜 폴더에서 리포트를 연다 | 칸 44개 · 2,231행 · 10/01~10/20 |
| Step 2 CLAUDE.md 만들기 | 성과 기준 4가지를 묻고 답대로 만든다 (기본 전환 14일 · 낭비 1만 원 · 효자 ROAS 300% · 목표 없음) | 제목 4개 · 판단 기준 줄 |
| Step 3 분석 스킬 만들기 | coupang-ad-dashboard 만들기 | 파일 셋이 생긴다 |
| Step 4 첫 분석기 | 「쿠팡 광고 분석해줘」 | 탭 6개 · 낭비 검토 3개 |
| Step 5 원본과 맞춰 보기 | 「원본 엑셀과 분석기 합계를 맞춰 봐줘」 | 1,793,660원 · 4,293,160원 · 173건 |
| Step 6 3회 구동 | 자료만 바꾸고, CLAUDE.md 기준만 바꿔 다시 | 낭비 검토 3 → 6 → 1 · 결과물 폴더 3개 |
| Step 7 링크로 나누기 | 가장 최근 결과물을 넷리파이 드롭으로 올린다 | 링크가 다른 브라우저에서 열린다 |

**Step 4 첫 분석기와 Step 5 원본과 맞춰 보기는 건너뛰지 마세요.** 이 둘이 없으면 결과물이 남지 않습니다.

## 내 리포트로 할 때

광고센터 > 광고 보고서 > 매출 성장 광고 보고서에서 받은 파일을 **이름 그대로** 둡니다.
`데이터/` 안에 리포트 마지막 날짜로 폴더를 만들고 (예 `2026-10-25`) 그 안에 넣습니다.
분석기는 이름이 가장 뒤인 날짜 폴더를 읽습니다. 지난 자료는 지난 폴더에 그대로 남습니다.

## 자주 나오는 질문

**스킬이 안 잡혀요**
Code 탭에서 고른 폴더가 `실습자료` 인지 보세요. 그 위 폴더를 고르면 스킬을 못 찾습니다.

**분석기 링크를 아무에게나 보내도 되나요**
안 됩니다. 분석기 파일 안에 광고 숫자가 들어 있어 링크를 아는 사람은 누구나 봅니다. 내 자료 분석기는 팀 채널에만 나누세요.

**분석기가 광고를 꺼 주나요**
아닙니다. 제안만 합니다. 키워드를 끄거나 입찰을 바꾸는 일은 광고센터에서 사람이 합니다.

**샘플 자료는 진짜 회사 자료인가요**
아닙니다. 실제 쿠팡 매출 성장 광고 보고서를 고쳐 만든 가상 브랜드 「노을뷰티」 자료입니다. 브랜드 · 상품 · 캠페인 · 검색어 · ID 를 모두 가짜로 바꾸고 금액도 바꿨습니다. 칸 44개와 값 형식은 실제 보고서와 같습니다.
