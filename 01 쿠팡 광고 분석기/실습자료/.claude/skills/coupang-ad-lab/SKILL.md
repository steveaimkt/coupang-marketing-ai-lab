# 쿠팡 광고 분석기 직접 만들기

> ⛔ **자동 실행 금지.** 한 응답 = 한 단계 = 질문 하나. 답을 받기 전에는 다음으로 가지 않는다.
> "전부 해줘"라고 해도 한 단계씩 간다. 선택은 번호로 준다. 전문용어에는 괄호로 한 줄 풀이를 붙인다.
> 자료에 없는 숫자를 지어내지 않는다.

## 참조 파일 지도

| 단계 | 먼저 읽을 파일 |
|---|---|
| Step 0 | `requirements.txt` (설치할 것 둘) |
| Step 2 | `assets/claude-md.md` (CLAUDE.md 원본) · `scripts/claude_md.py` |
| Step 3 | `scripts/setup.py` · `assets/analyzer-config.md` |
| Step 4~Step 5 | 만들어진 `.claude/skills/coupang-ad-dashboard/SKILL.md` |
| Step 6 | `reference.md` §3회 구동 (반드시) |
| Step 7 | `reference.md` §배포 |
| 실습2 | `config.md` |
| 막힐 때 | `reference.md` §에러 대응 |

읽지 않고 진행하지 않는다.

## 단계마다 지킬 형식

시작 세 줄(지금 보이는 것 · 지금 하실 것 · 확인하실 것)로 열고,
마무리 세 줄(✅ 방금 한 것 · 💡 왜 했나 · ▶ 다음은)과 질문 하나로 끝낸다.
작업 폴더의 `진행상황.md` 를 시작할 때 읽고 단계가 끝날 때마다 고친다.

# 1단계 · 소개

## 없으면 생기는 문제

```
매주 월요일    광고센터에서 매출 성장 광고 보고서를 받는다 (2,000줄이 넘는다)
              →  엑셀에서 피벗을 다시 만든다
              →  지면별, 키워드별로 나눠 본다
              →  "그래서 어떤 키워드를 끄지?" 까지 한 시간이 걸린다
```

**같은 일을 매주 처음부터 한다.** 지난주에 잘 된 방법이 엑셀 파일 안에 묻혀 있다.

## 확인 질문

질문 하나 드릴게요. 지난주 광고 보고서를 볼 때 가장 오래 걸린 일이 무엇이었나요?

```
  1  피벗과 합계 만들기
  2  끌 키워드 고르기
  3  팀에 결과 알리기
  4  리포트를 받아 본 적이 없다
```

## [2/8] Step 1 · 입력 확인 (짧음)

`데이터/` 안에서 **가장 최근 날짜 폴더**의 매출 성장 광고 보고서(`*pa_daily_keyword*.xlsx`)를 찾는다. 처음에는 샘플 `데이터/2026-10-20/` 하나가 들어 있다.
파일을 열어 폴더 · 파일 이름 · 시트 · 칸 수 · 행 수 · 기간을 보여 준다.

```

                 시트 Sheet1 · 칸 44개 · 2,231행 · 2026-10-01~2026-10-20
지금 하실 것      이 파일로 할지 고릅니다

  1  샘플로 진행 (추천)
  2  내 광고 보고서로 진행
     데이터/ 안에 리포트 마지막 날짜로 폴더를 만들고 (예 2026-10-25)
     광고센터에서 받은 파일을 이름 그대로 넣은 뒤

확인하실 것      칸 44개, 행 수, 기간이 화면에 보입니다
```

**원본 파일은 고치지 않는다.** 읽기만 한다. 파일 이름도 바꾸지 않는다. 날짜는 폴더 이름이 맡는다.

## [3/8] Step 2 · CLAUDE.md 만들기 ★ (보통)

**기준을 먼저 잡는다.** 다음 단계에서 만드는 분석 스킬은 이 파일을 따른다.

```
지금 하실 것     2가지를 고릅니다

  전환 기준 (광고를 누른 뒤 며칠 안의 주문까지 칠지)
    1  14일 (추천 · 샘플 정답이 이 기준입니다)
    2  1일

  목표 ROAS (광고비 대비 매출 목표)
    1  정하지 않음 (추천)
    2  숫자로 정함 (예 300)
```

답을 받으면 CLAUDE.md 를 만든다. (전환 1일이면 `--attribution-days 1`, 목표가 있으면 `--target-roas 숫자`)

```
python3 .claude/skills/coupang-ad-lab/scripts/claude_md.py --workspace . --attribution-days 14
```

만든 CLAUDE.md 를 열어 제목 4개를 짚는다.

```
나는 누구인가    무슨 일을 하는가 · 자료 넣는 자리 · 일하는 순서
지표 계산법      ROAS 는 합계끼리 나눈다 · 「-」 줄은 추천에서 뺀다
판단 기준        attribution_days · waste_cost_krw 10000 · star_roas_pct 300  ← 생성기가 이 줄을 읽는다
하지 않는 것     원본을 고치지 않는다 · 묻지 않고 배포하지 않는다
```


## [7/8] Step 6 · 3회 구동 ★★ (보통)

**`reference.md` §3회 구동을 먼저 읽는다.**

```
1회   기본 자료로        →  도는가          (Step 4~Step 5 에서 이미 했습니다)
2회   자료만 바꿔서       →  스킬을 안 고쳐도 도는가
3회   기준만 바꿔서       →  결과가 따라오는가
```

### 2회차 · 자료 교체 (자르지 않는다)

```
지금 하실 것     내 리포트가 있으면 1번, 없으면 2번을 고릅니다

  1  내 광고 보고서로
     광고센터 > 광고 보고서 > 매출 성장 광고 보고서에서 받은 파일을
     데이터/ 안 새 날짜 폴더(예 2026-10-25)에 이름 그대로 넣는다
  2  샘플 2회차로
     보관/2026-11-09 폴더를 데이터/ 안으로 옮긴다

  넣은 다음 이렇게 칩니다

  쿠팡 광고 분석해줘
```

**성공 판정** · 스킬 파일을 한 글자도 안 고쳤는데 가장 최근 날짜 폴더를 스스로 찾아 돈다. 기간과 합계가 1회차와 다르다.
1회차 자료는 `데이터/2026-10-20/` 에 그대로 남는다. 덮어쓰지 않는다.
샘플 2회차면 낭비 검토가 3개에서 6개로 바뀐다. 키워드도 탈모 샴푸 · 남성 마스크팩 등으로 바뀐다.

자료만 바꿨는데 분석기가 다시 나왔나요? 1회차와 무엇이 달라졌나요?

⏸

### 3회차 · 기준 변경

```
지금 하실 것     아래 한마디를 칩니다

  CLAUDE.md 의 낭비 기준을 2만 원으로 바꾸고 다시 분석해줘

확인하실 것      CLAUDE.md 「판단 기준」 의 waste_cost_krw 가 10000 에서 20000 으로 바뀌고
                 낭비 검토 건수가 줄어듭니다. 스킬 파일은 그대로입니다
```

**성공 판정** · 샘플 2회차 기준으로 낭비 검토가 6개에서 1개가 된다. 탈모 샴푸 (20,220원) 하나만 남는다.

세 번의 결과를 `결과물/3회구동.md` 에 표로 남긴다.

```
| 회차 | 바꾼 것 | 손댄 파일 | 기간 | 광고비 | 낭비 검토 |
| 1 | 없음 | 없음 | ... | ... | ... |
| 2 | 자료 | 없음 | ... | ... | ... |
| 3 | 낭비 기준 10000 → 20000 | CLAUDE.md 한 줄 | ... | ... | ... |
```

**2회 줄의 «손댄 파일: 없음» 과 3회 줄의 «CLAUDE.md 한 줄» 이 이 표의 핵심입니다.** 기준을 바꾸려고 스킬을 고치지 않았습니다.
