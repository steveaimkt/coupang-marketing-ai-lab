# reference · 쿠팡 광고 분석기 직접 만들기

> SKILL.md 가 짧아야 지시를 잘 따른다. 자세한 것은 여기 둔다.
> 필요할 때만 읽는다.

## 폴더 모양

```
01 쿠팡 광고 분석기/
├── README.md · 프롬프트-툴킷.md
├── 실습자료/                         ← Code 탭에서 이 폴더를 연다
│   ├── CLAUDE.md                     Step 2 에서 생긴다 · 이 폴더의 기준 (판단 기준이 여기 있다)
│   ├── .claude/skills/
│   │   ├── coupang-ad-lab/           실습 스킬 (오늘 길 안내)
│   │   └── coupang-ad-dashboard/     분석 스킬 (Step 3 에서 생긴다 · 다음 주에도 쓴다)
│   ├── 데이터/
│   │   └── 2026-10-20/               날짜 폴더 · 리포트 마지막 날짜
│   │       └── A00000000_pa_daily_keyword_20261001_20261020.xlsx   받은 이름 그대로
│   ├── 보관/2026-11-09/              2회차 샘플 · 데이터/ 로 옮겨 쓴다
│   ├── 결과물/                       만들 때마다 새 폴더가 쌓인다
│   │   ├── 2026-10-20_1405/          1회차 · index.html · styles.css · script.js · 검증결과.md
│   │   ├── 2026-11-09_1420/          2회차
│   │   ├── 2026-11-09_1431/          3회차
│   │   └── 3회구동.md
│   ├── 배포용/                       넷리파이에 올리는 세 파일 (가장 최근 결과물에서 복사)
│   └── 진행상황.md
├── 완성예제/                         분석 스킬 · 분석기 완성본
└── 검증/                             3회 구동 기록 견본
```

**읽는 규칙** · `데이터/` 안 날짜 폴더 중 이름이 가장 뒤인 폴더의 `*pa_daily_keyword*.xlsx` 하나를 읽는다.
같은 폴더에 둘이 있으면 멈추고 묻는다. 없으면 날짜 폴더를 만들라고 알린다.

**내놓는 규칙** · 분석기를 만들 때마다 `결과물/{자료 날짜}_{만든 시각 HHMM}/` 새 폴더에 넣는다. 지난 폴더는 덮어쓰지 않는다.
자료 날짜는 읽은 날짜 폴더 이름(`2026-10-20`), 시각은 컴퓨터 현지 시각이다. 같은 이름이 있으면 `_2`, `_3` 을 붙인다.
**가장 최근 결과물**은 `결과물/` 안 폴더 이름순 마지막이다. 원본 대조(`verify.py`), 브라우저 확인(`verify-browser.cjs`), 배포는 따로 말이 없으면 이 폴더를 쓴다.
지난 결과물을 맞춰 볼 때는 `verify.py` 에 `--dir 2026-10-20_1405` 처럼 폴더 이름을 붙인다.

## 출력 스키마

분석기는 탭 6개다. 이름과 순서는 분석 스킬 `config.md` 의 `menu_items` 를 따른다.

| 탭 | 들어가는 것 |
|---|---|
| 대시보드 | 요약 문장, 광고비·전환매출·ROAS·주문·CTR·CPC·CVR·CPA 카드, 일별 광고비와 매출 차트, 캠페인 ROAS 상위 5 |
| 일별 | 날짜순 광고비·매출·ROAS, 노출 → 클릭 → 주문 단계별 수치 |
| 지면 | 검색 영역 · 비검색 영역 · 외부 채널별 광고비·매출·ROAS·광고비 비중 |
| 키워드 | 낭비 검토·효자 건수, 검색창, 정렬되는 성과표 |
| 인사이트 | 주문 없는 지출, 고효율 키워드, 지면 비교, 클릭 대비 주문 |
| 실행 계획 | 긴급 · 이번 주 · 이번 달로 나눈 제안과 근거 숫자 |

계산은 합계로 한다. ROAS = 전환매출 합계 ÷ 광고비 합계 × 100. 줄마다 ROAS를 낸 뒤 평균하지 않는다.

## 판단 기준

| 분류 | 기준 (기본값) | 바꾸는 곳 |
|---|---|---|
| 낭비 검토 | 광고비 10,000원 이상 · 주문 0건 | CLAUDE.md `waste_cost_krw` |
| 효자 | ROAS 300% 이상 · 주문 1건 이상 | CLAUDE.md `star_roas_pct` · `minimum_orders_for_star` |
| 가능성 검토 | ROAS 100% 이상 300% 미만 | CLAUDE.md `potential_roas_pct` |
| 키워드 미지정 | 키워드가 `-` 인 줄 | 합계에는 넣고 추천에서는 뺀다 |

Step 2 에서 전환 기준 · 낭비 기준 · 효자 기준 · 목표 ROAS 4가지를 기본값과 함께 묻고, 답을 받은 뒤 그대로 CLAUDE.md 를 만든다.
묻지 않고 기본값으로 만들지 않는다. 샘플 정답은 기본값(전환 14일 · 낭비 1만 원 · 효자 300% · 목표 없음) 기준이다.

숫자로 적는다. "많으면" 이 아니라 "1만 원 이상이면" 이라고 적는다.
**금칙어** · 전반적으로 · 대체로 · 양호한 · 개선이 필요한. 이런 말이 나오면 기준이 비어 있다는 뜻이다.

## 샘플 정답

가상 브랜드 「노을뷰티」. 실제 쿠팡 매출 성장 광고 보고서를 고쳐 만들었다. 브랜드 · 상품 · 캠페인 · 검색어 · ID 는 가짜이고 칸 44개는 같다.

| | 1회차 `데이터/2026-10-20/` | 2회차 `보관/2026-11-09/` → `데이터/` |
|---|---|---|
| 기간 | 2026-10-01~2026-10-20 | 2026-10-21~2026-11-09 |
| 행 수 | 2,231 | 2,534 |
| 광고비 | 1,793,660원 | 4,667,890원 |
| 전환매출 (14일) | 4,293,160원 | 12,060,830원 |
| 주문 (14일) | 173건 | 487건 |
| ROAS | 239.4% | 258.4% |
| 검색 키워드 (「-」 제외) | 61개 | 72개 |
| 낭비 검토 (1만 원) | 3개 · 노을뷰티 약산성 샴푸 · 노을뷰티 헤어 오일 · 진정 마스크팩 | 6개 · 탈모 샴푸 · 남성 마스크팩 · 노을뷰티 헤어 오일 · 헤어 에센스 · 노을뷰티 쿠션 21호 · 수분 마스크팩 |
| 낭비 검토 (2만 원) | 0개 | 1개 · 탈모 샴푸 |

낭비 검토는 「캠페인 + 광고그룹 + 지면 + 키워드」 묶음 하나를 한 항목으로 센다. 같은 키워드라도 캠페인이 다르면 따로 센다.

## 3회 구동

같은 스킬을 세 번 돌려 도구인지 확인하는 절차다.

| 회차 | 무엇을 바꾸나 | 무엇을 보나 | 샘플이면 |
|---|---|---|---|
| 1회차 | 아무것도 (기본) | 일단 도는가 | 낭비 검토 3개 |
| 2회차 | 자료만 교체 | 스킬을 안 고쳐도 도는가 | 낭비 검토 6개 · 기간과 합계가 바뀐다 |
| 3회차 | 낭비 기준만 변경 (1만 원 → 2만 원) | 기준이 결과를 바꾸는가 | 낭비 검토 1개 |

세 번 다 돌면 도구다. 한 번만 도는 것은 대화이지 도구가 아니다.

**2회차에 하는 것은 `데이터/` 에 새 날짜 폴더를 넣는 것뿐이다.** 스킬 폴더 안의 파일은 하나도 고치지 않는다. 1회차 폴더도 지우지 않는다.
**3회차에 바꾸는 것은 CLAUDE.md 「판단 기준」 의 `waste_cost_krw` 한 줄뿐이다.** 스킬 파일은 2·3회차 내내 그대로다.
**3회차까지 돌고 나면 `결과물/` 안에 폴더가 3개 있다.** 회차마다 새 폴더에 쌓이고, 앞 회차 폴더는 그대로 남는다.

## 배포

넷리파이 드롭(`https://app.netlify.com/drop`)을 쓴다. 폴더를 끌어다 놓으면 주소가 나온다.

| 지킬 것 | 왜 |
|---|---|
| 올리기 전에 사람에게 묻는다 | 분석기 `script.js` 안에 광고 숫자가 그대로 들어 있다. 링크를 아는 사람은 누구나 본다 |
| 가장 최근 결과물에서 세 파일만 `배포용/` 에 복사한다 | 결과물 폴더의 검증 기록(`검증결과.md` · `검산.json`)은 보는 사람에게 필요 없다. 화면에 필요한 것만 올린다 |
| `배포용/` 은 `결과물/` 밖에 둔다 | `결과물/` 안에는 분석기 폴더만 쌓아야 이름순 마지막이 곧 가장 최근 결과물이다 |
| 무료 계정으로 로그인한 뒤 올린다 | 로그인하지 않고 올린 사이트는 곧 지워진다 |
| 내 자료 분석기 링크는 팀 안에서만 나눈다 | 단톡방 · 공개 게시판에 올리지 않는다 |

## 자주 나오는 질문

**코딩을 몰라도 되나요**
됩니다. 수강생은 한국어로 말하고, 나온 화면이 맞는지만 봅니다. 명령은 클로드 코드가 칩니다.

**광고센터 파일 이름을 그대로 써도 되나요**
됩니다. 이름은 그대로 두고 `데이터/` 안에 리포트 마지막 날짜로 폴더(예 `2026-10-25`)를 만들어 넣습니다. 분석기는 가장 최근 날짜 폴더를 읽습니다.

**분석기가 광고를 꺼 주나요**
아닙니다. 분석기는 제안만 합니다. 실제 키워드를 끄거나 입찰을 바꾸는 일은 광고센터에서 사람이 합니다.

## 에러 대응

| 에러 | 무슨 뜻 | 어떻게 |
|---|---|---|
| `ModuleNotFoundError: No module named 'yaml'` | PyYAML이 없다 | `python3 -m pip install -r .claude/skills/coupang-ad-lab/requirements.txt` |
| `시트를 선택해 sheet_name에 저장하세요` | 엑셀에 시트가 여러 개다 | 보이는 시트 이름 중 하나를 골라 분석 스킬 `config.md` 의 `sheet_name` 에 적는다 |
| `필수 열 누락: [...]` | 매출 성장 광고 보고서가 아닌 파일을 넣었거나 칸이 빠졌다 | 광고센터 > 광고 보고서 > 매출 성장 광고 보고서로 받은 파일인지 본다 |
| `CLAUDE.md 가 없습니다` | Step 2 를 건너뛰었다 | `scripts/claude_md.py` 로 먼저 만든다 |
| `설정과 화면이 일치하지 않습니다` | 기준을 바꾼 뒤 분석기를 다시 안 만들었다 | "쿠팡 광고 분석해줘" 로 다시 만든 뒤 맞춰 본다 |
| `가장 최근 결과물(...)이 지금 자료로 만든 것이 아닙니다` | 새 날짜 폴더를 넣고 분석기를 다시 안 만들었다 | "쿠팡 광고 분석해줘" 로 다시 만든 뒤 맞춰 본다. 지난 결과물이면 `--dir 폴더이름` 을 붙인다 |
| `결과물이 아직 없습니다` | Step 4 를 건너뛰었다 | "쿠팡 광고 분석해줘" 로 분석기부터 만든다 |
| `분석 스킬이 이미 있습니다` | Step 3 을 2번 돌렸다 | 새로 만들지 않고 있는 스킬로 계속한다 |
| `config.md는 작업폴더/.claude/skills/스킬이름 안에 있어야 합니다` | 실습자료/ 가 아닌 폴더를 Code 탭에서 열었다 | `데이터/` 와 `.claude/` 가 보이는 `실습자료/` 폴더를 열고 다시 한다 |
| `매출 성장 광고 보고서를 찾지 못했습니다` | 파일을 데이터/ 바로 아래에 넣었다 | 날짜 폴더를 만들고 그 안에 넣는다 |
| `폴더에 매출 성장 광고 보고서가 2개 있습니다` | 같은 날짜 폴더에 두 파일 | 하나만 남긴다 |
