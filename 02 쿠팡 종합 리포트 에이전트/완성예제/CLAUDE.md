# 노을뷰티 쿠팡 종합 리포트 에이전트

> 이 폴더에서 일할 때 클로드 코드가 가장 먼저 읽는 기준입니다. 스킬과 서브에이전트는 이 기준을 따릅니다.
> 기준을 바꾸려면 이 파일의 「판단 기준」 한 줄을 고칩니다. 코드 안에 숫자를 다시 적지 않습니다.

## 나는 누구인가

쿠팡 셀러 인사이트·광고센터 엑셀 4종으로 이번 달 누적 종합 리포트를 만들고, 사람의 확인을 받아 노션과 메신저로 보낸다.
계산과 인사이트는 파이썬 규칙(`generate_report.py`)이 맡는다. 매번 같은 결과가 나온다.

**자료 넣는 자리**

```
리포트 자료/노을뷰티/{날짜}/        날짜 = 리포트 마지막 날 (2026-10-20 꼴)
  ├── A0000…_pa_daily_keyword_….xlsx                 매출 성장 광고 보고서 (받은 이름 그대로)
  ├── A0000…_nca_daily_creative_….xlsx               신규 구매 고객 확보 광고 보고서
  ├── SELLER_INSIGHTS_DAILY_SUMMARY_METRICS_(0).xlsx   일별 판매
  └── SELLER_INSIGHTS_VENDOR_ITEM_METRICS_(0).xlsx     상품별 판매
```

경로를 따로 말하지 않으면 `리포트 자료/노을뷰티/` 안에서 **이름이 가장 뒤인 날짜 폴더**를 쓴다.

**결과물 쌓이는 자리**

```
결과물/{자료 날짜}_{만든 시각 HHMM}/   리포트를 만들 때마다 새 폴더 (같은 이름이 있으면 _2, _3)
  ├── 노을뷰티_광고리포트_2026-10-20.html   리포트
  ├── 검토결과.md                            리포트검토 서브에이전트의 결과
  └── 메신저요약.txt                          messenger.py --dry-run 으로 본 요약
```

따로 말하지 않으면 노션 발행 · 검토 · 수정 대응 · 메신저 요약은 **가장 최근 결과물 폴더**(`결과물/` 안 이름순 마지막)의 리포트를 쓴다.

**일하는 순서** · 「광고 리포트 작성하자」 → `coupang-report` 스킬

```
Step 1   데이터 분석 · 1차 리포트
Step 2   목표와 마케팅 플랜 묻기          ← 사람
Step 3   최종 리포트
Step 3.5 리포트검토 서브에이전트          ← 원본으로 다시 센다
Step 4   노션 발행                        ← 사람 승인 뒤
Step 5   수정 대응 (HTML · 노션 페이지 · 노션 다운로드 파일 3곳)
Step 6   메신저 요약                      ← 사람 승인 뒤
```

**명령** (이 폴더에서)

```bash
python3 -m pip install -r requirements.txt
python3 generate_report.py --data-dir "리포트 자료/노을뷰티/2026-10-20" --brand "노을뷰티" --summary-only
python3 generate_report.py --data-dir "…" --brand "노을뷰티" --target-sales 20000000 --next-target-sales 22000000 --no-open
python3 generate_report.py --data-dir "…" --brand "노을뷰티" --notion --no-open
python3 messenger.py --dry-run
```

## 지표 계산법

- **ROAS = 전체 매출 ÷ 총 광고비 × 100** (광고 전환매출 기준이 아니다). 화면과 요약에 「전체 매출 기준」 을 붙인다
- **광고비는 매출 성장 광고 보고서 + 신규 구매 고객 확보 광고 보고서를 날짜별로 더한다.** 판매 기간 밖 날짜는 자르고, 제품 트렌드 계산에만 전체를 쓴다
- **일별 판매 파일 맨 아래 날짜 빈 합계 행은 빼고 센다.** 더하면 매출이 정확히 2배가 된다
- 비율은 합계끼리 나눈다. 줄마다 낸 비율을 평균하지 않는다
- 월간 예측 · 최근 7일 가중 평균 50% + 전체 평균 50%
- 금액 표기 · 1억 이상 「1.2억원」 · 1만 이상 「123만원」 · 그 아래 「9,999원」

## 판단 기준

생성기(`data_loader.py`)가 아래 줄을 그대로 읽는다. 말로 기준을 바꾸면 이 줄만 고친다.

- 브랜드: 노을뷰티
- 주문변화_기준_pct: 30
- 매출편중_기준_pct: 70

| 이름 | 뜻 |
|---|---|
| 주문변화_기준_pct | 상품별 광고 주문이 최근 7일과 그 앞 기간 사이에 이 % 이상 변하면 따로 뺀다 |
| 매출편중_기준_pct | 한 상품이 매출의 이 % 를 넘으면 「매출 편중 위험」 경고. 넘지 않고 50% 만 넘으면 「주력 상품 매출 비중」 안내 |

숫자로 적는다. 「많이 변하면」 이 아니라 「30% 이상이면」 이다.

## 하지 않는 것

- **사람 확인 없이 밖으로 보내지 않는다.** 노션 발행과 메신저 발송은 「올려도 된다」 는 답을 받은 뒤에만 한다
- **검토를 통과하지 못한 리포트는 배포하지 않는다**
- **원본 엑셀과 파일 이름을 고치지 않는다.** 읽기만 한다
- **키를 파일이나 화면에 적지 않는다.** 노션 키와 웹훅 주소는 `.env` 에만 둔다
- **리포트 자료 · 결과물 · .env 를 밖으로 올리지 않는다** (`guard_exfil` 훅이 멈춘다)
- **이미 있는 리포트를 덮어쓰지 않는다.** 새로 만들면 새 결과물 폴더에 들어간다. 고칠 때는 그 폴더의 HTML 을 Edit 로 그 자리에서 고친다
- **사람이 손본 리포트를 새 자동 리포트로 바꿔 올리지 않는다** (`guard_force_html` 훅이 멈춘다)
- 자료에 없는 숫자를 지어내지 않는다. 추정은 추정이라고 적는다
