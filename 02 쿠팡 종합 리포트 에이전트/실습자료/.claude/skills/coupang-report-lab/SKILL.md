# 쿠팡 종합 리포트 에이전트 직접 운영하기

> ⛔ **자동 실행 금지.** 한 응답 = 한 단계 = 질문 하나. 답을 받기 전에는 다음으로 가지 않는다.
> "전부 해줘"라고 해도 한 단계씩 간다. 선택은 번호로 준다. 전문용어에는 괄호로 한 줄 풀이를 붙인다.
> 자료에 없는 숫자를 지어내지 않는다. 노션 발행과 메신저 발송은 사람의 승인 없이 하지 않는다.

## 단계마다 지킬 형식

시작 세 줄(지금 보이는 것 · 지금 하실 것 · 확인하실 것)로 열고,
마무리 세 줄(✅ 방금 한 것 · 💡 왜 했나 · ▶ 다음은)과 질문 하나로 끝낸다.
작업 폴더의 `진행상황.md` 를 시작할 때 읽고 단계가 끝날 때마다 고친다.

## [3/8] Step 2 · CLAUDE.md 만들기 ★ (보통)

**기준을 먼저 잡는다.** 스킬과 서브에이전트는 이 파일을 따른다.

판단 기준 2가지를 고르게 한다. 기본값을 고르면 그대로 쓴다.

```
지금 하실 것     2가지를 고릅니다

  주문 변화 기준 (상품별 광고 주문이 이 % 넘게 변하면 따로 뺀다)
    1  30% (추천 · 샘플 정답이 이 기준입니다)
    2  직접 정함

  매출 편중 기준 (한 상품이 매출의 이 % 를 넘으면 경고)
    1  70% (추천 · 샘플 정답이 이 기준입니다)
    2  직접 정함
```

답을 받으면 설치 도구로 CLAUDE.md 를 만든다. (내 자료면 `--brand` 에 내 브랜드)

```
python3 .claude/skills/coupang-report-lab/scripts/install.py claude-md --brand 노을뷰티 --trend 30 --concentration 70
```

만든 CLAUDE.md 를 열어 제목 4개를 짚는다.

```

지표 계산법      ROAS 는 전체 매출 기준 · 광고 합계는 판매 기간 · 합계 행은 뺀다
판단 기준        주문변화_기준_pct · 매출편중_기준_pct  ← 생성기가 이 줄을 읽는다
하지 않는 것     사람 확인 없이 보내지 않는다 · 키를 적지 않는다 · 원본을 고치지 않는다
```

```
✅ 방금 한 것   이 폴더의 기준을 CLAUDE.md 한 장에 적었습니다
💡 왜 했나      기준이 한 곳에 있어야 스킬과 에이전트가 같은 숫자로 판단합니다
▶ 다음은       이 기준을 따르는 스킬과 검토 서브에이전트를 넣습니다
```

## [6/8] Step 5 · 3회 구동 ★★ (보통)

**`reference.md` §3회 구동을 먼저 읽는다.**

```
1회   기본 자료로        →  도는가          (Step 4 에서 이미 했습니다)
2회   자료만 바꿔서       →  스킬을 안 고쳐도 도는가
3회   기준만 바꿔서       →  결과가 따라오는가
```

### 2회차 · 자료 교체 (자르지 않는다)

```
지금 하실 것     내 자료가 있으면 1번, 없으면 2번을 고릅니다

  1  내 자료로
     리포트 자료/{브랜드}/ 안에 새 날짜 폴더(예 2026-11-30)를 만들고 4종을 이름 그대로 넣는다
  2  샘플 2회차 자료로
     보관/2026-11-09 폴더를 리포트 자료/노을뷰티/ 안으로 옮긴다

  넣은 다음 이렇게 칩니다

  광고 리포트 작성하자
```

**성공 판정** · 스킬과 CLAUDE.md 를 한 글자도 안 고쳤는데 가장 최근 날짜 폴더를 읽어 돈다.
샘플 2회차 자료면 매출 22,900,440원, 매출 1위 PDRN 앰플이 59.5% 이고 「주력 상품 매출 비중」 안내가 나온다.

자료만 바꿨는데 리포트가 다시 나왔나요? 1회차와 무엇이 달라졌나요?

⏸

### 3회차 · 기준 변경

```
지금 하실 것     아래 한마디를 칩니다

  CLAUDE.md 의 매출 편중 기준을 50% 로 바꾸고 리포트를 다시 만들어줘

확인하실 것      CLAUDE.md 「판단 기준」 의 매출편중_기준_pct 가 70 에서 50 으로 바뀌고
                 「주력 상품 매출 비중」 안내가 「매출 편중 위험」 경고로 바뀝니다 (PDRN 앰플 59.5%)
```

세 번의 결과를 `output/3회구동.md` 에 표로 남긴다.

```
| 회차 | 바꾼 것 | 손댄 파일 | 기간 | 매출 | 편중 인사이트 |
| 1 | 없음 | 없음 | ... | ... | ... |
| 2 | 자료 | 없음 | ... | ... | ... |
| 3 | 매출 편중 기준 70 → 50 | CLAUDE.md 한 줄 | ... | ... | ... |
```

**3회 줄의 「CLAUDE.md 한 줄」 이 이 실습의 핵심입니다.** 기준을 바꾸려고 코드나 스킬을 고치지 않았습니다.

기준 한 줄만 바꿨는데 리포트가 따라왔습니다. 왜 그럴까요?

⏸

## [7/8] Step 6 · 노션 발행 (보통)

**`reference.md` §노션을 먼저 읽는다.** 노션 키가 없으면 이 단계는 건너뛰고 Step 7 로 간다.

```
지금 하실 것     노션 준비가 되셨는지 고릅니다

  1  .env 에 NOTION_API_KEY · NOTION_PAGE_ID 를 넣었다
  2  아직 없다 (건너뛰기)
```

노션 준비가 되셨나요? 번호로 답해 주세요.

## 안 되실 때

```
1  아래 표에서 증상을 찾는다
2  없으면 오류 메시지를 그대로 붙여 넣고 "이게 안 되는데 왜 그런지 찾아줘"
3  3번 해도 안 되면 챕터 폴더의 완성예제/ 에서 꺼내 쓰고 다음 단계로 간다
```

| 증상 | 원인 | 대처 |
|---|---|---|
| `No module named 'pandas'` 등 | 파이썬 부품이 없다 | Step 0 의 설치 명령을 다시 돌린다 |
| `CLAUDE.md 가 없습니다` | Step 2 를 건너뛰었다 | Step 2 로 돌아가 CLAUDE.md 부터 만든다 |
| 「광고 리포트 작성하자」 가 안 잡힌다 | 새로 넣은 스킬을 아직 못 읽었다 | 같은 폴더로 새 세션을 열고 「실습 이어서」 |
| 매출이 2배로 나온다 | 합계 행까지 더했다 | 생성기를 쓰면 빠진다. 손으로 셌다면 맨 아래 행을 뺀다 |
| 3회차에 결과가 그대로다 | config.md 에만 적었다 | CLAUDE.md 「판단 기준」 줄을 고친다 |
| 노션 업로드 실패 | 키나 페이지 공유가 없다 | `.env` 를 확인하고, 노션 페이지에서 통합 연결을 허용한다 |
| 웹훅이 없다는 메시지 | `.env` 에 웹훅이 없다 | 복사용 요약만 쓰거나 `.env` 에 넣는다 |

자세한 오류 대응은 `reference.md` §에러 대응에 있다.
