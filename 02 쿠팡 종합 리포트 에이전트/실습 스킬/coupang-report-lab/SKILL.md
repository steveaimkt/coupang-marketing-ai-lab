**운영체제를 보고 명령을 바꿔 친다.** 맥은 터미널(zsh) 명령, 윈도우는 파워셸 명령이다. 바꿔 치는 법은 위 «운영체제를 보고 명령을 바꿔 친다» 표를 따른다.
점검 도구가 운영체제에 맞는 설치 명령을 점검표 아래에 만들어 보여 준다. 설치는 클로드가 그 명령으로 직접 한다. 묻고 답을 받은 뒤에만 친다.

**python 이 없을 때** · 점검 도구도 돌지 않는다 (확인 · 맥 `python3 --version` · 윈도우 `py --version`). 설치 명령을 보여 주고 묻는다.
맥은 `brew install python` (Homebrew 가 없으면 `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"` 한 줄을 보여 주고 **수강생이 터미널 앱에서 직접** 친다. 비밀번호를 묻기 때문이다. 클로드는 비밀번호를 받지 않는다).
윈도우는 `winget install -e --id Python.Python.3.12` (winget 이 없으면 마이크로소프트 스토어에서 «앱 설치 관리자» 를 먼저 설치).
설치 뒤 PATH 는 새 세션부터 잡힌다. 돌아와서 칠 말을 먼저 알려 주고, Code 탭에서 새 세션을 열고 같은 폴더를 고르게 한다.

없음이 한 줄이라도 있으면 그 이름과 점검표 아래 설치 명령을 보여 주고 묻는다. 묻기 전에는 설치하지 않는다.

```
없음      openpyxl · kaleido   (점검표에 없음으로 나온 이름을 그대로)
```

이 명령으로 없는 부품을 설치할까요?

## [7/8] Step 6 · 노션 발행 (보통)

**`reference.md` §노션을 먼저 읽는다.** 노션을 쓰지 않으면 이 단계는 건너뛰고 Step 7 로 간다.
노션 화면은 클로드가 열 수 없어 순서만 보여 준다. 화면 이름은 버전에 따라 조금 다를 수 있다고 함께 알린다.

```

  2  페이지 ID 찾기    리포트를 올릴 노션 페이지 주소의 끝 32자리(영문과 숫자)를 복사한다
  3  페이지 연결       그 페이지 오른쪽 위 ··· > 연결에서 방금 만든 통합을 허용한다
  4  .env 에 넣기      .env 를 열어 NOTION_API_KEY= 뒤에 키, NOTION_PAGE_ID= 뒤에 32자리를 붙여 넣고 저장한다

  1  4단계까지 했다 (.env 에 넣고 저장했다)
  2  키와 32자리를 복사했다 (.env 를 열어 주세요)
```
