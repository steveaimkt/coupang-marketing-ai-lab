# 02 쿠팡 종합 리포트 에이전트

> 8교시 「쿠팡 종합 리포트 에이전트 직접 운영하기 실습」 자료입니다.
> CLAUDE.md 로 기준을 먼저 잡고, 그 기준을 따르는 단계형 스킬과 검토 서브에이전트를 넣은 뒤,
> 엑셀 4종으로 리포트를 뽑아 검토를 지나 노션과 메신저로 보냅니다.

## 결과물

1. CLAUDE.md (이 폴더의 기준 · 제목 4개)
2. 단계형 스킬 `coupang-report` · 「광고 리포트 작성하자」
3. 검토 서브에이전트 `리포트검토` · 원본으로 숫자를 다시 센다
4. 리포트 HTML · 노션 페이지 · 팀 채널 요약

리포트는 만들 때마다 작업 폴더의 `결과물/{자료 날짜}_{만든 시각 HHMM}/` 새 폴더에 쌓입니다. 앞의 리포트를 덮어쓰지 않습니다.
검토 결과(`검토결과.md`)와 메신저 요약(`메신저요약.txt`)도 같은 폴더에 들어갑니다.

## 시작하는 법

### 준비물

| | |
|---|---|
| 클로드 데스크탑 앱 | 유료 요금제로 로그인 · 위쪽 **Code** 탭을 씁니다 |
| python3 3.9 이상 | 없으면 Step 0 에서 클로드가 설치 명령(맥 터미널 · 윈도우 파워셸)을 보여 주고, 답을 받은 뒤 설치합니다 |
| 파이썬 부품 (pandas · openpyxl · plotly 등) | 미리 설치하지 않아도 됩니다. Step 0 에서 점검하고, 「설치할까요?」 에 답하면 클로드가 설치합니다 |
| 노션 키 · 슬랙 또는 디스코드 웹훅 | 선택 · Step 6 · 7 에서 `.env` 에 직접 넣습니다. 웹훅 만드는 법은 Step 7 에서 고른 쪽만 보여 줍니다 |

터미널을 열지 않습니다.

> **윈도우라면**
> 클로드가 운영체제를 보고 명령을 바꿔 칩니다. 설치 명령은 파워셸로 칩니다.
>
> | | 맥 | 윈도우 |
> |---|---|---|
> | 파이썬 | `python3` | `py` (없으면 `python`) |
> | .venv 파이썬 | `.venv/bin/python` | `.venv\Scripts\python` |
> | .env 열기 | `open -e .env` | `notepad .env` |
> | 새로고침 | Command + R | Ctrl + R |
> | 숨김 폴더 `.claude` 보기 | Finder 에서 Command + Shift + . | 파일 탐색기 > 보기 > 숨긴 항목 |

### 걸리는 시간

영상 26분 · 직접 하시면 1시간 안팎입니다.
최소선(Step 4 검토 통과까지)만 하면 30분입니다. Step 4-2 보고 고치기 · 실습2 · 노션(Step 6) · 메신저(Step 7)는 선택입니다.

### 회사 자료

내 판매 · 광고 자료를 쓰시려면 회사 보안 규칙에서 클로드에 올려도 되는 자료인지 먼저 확인하세요. 샘플만으로도 실습을 끝까지 할 수 있습니다.

### 따라 하기

1. 이름을 마음대로 정한 **빈 폴더**를 만듭니다 (예 `내리포트실습`)
2. 이 폴더의 `coupang-report-lab.zip` 을 **압축을 풀지 않고** 그 폴더에 넣습니다
3. 클로드 데스크탑 앱 위쪽 **Code** 탭에서 그 폴더를 고릅니다
4. 아래 한 줄을 칩니다

```text
이 폴더의 coupang-report-lab.zip 을 .claude/skills 에 풀고 쿠팡 리포트 에이전트 실습 시작
```

클로드가 zip 을 풀고 같은 대화에서 시작 화면을 보여 줍니다. Step 0 에서 만들 폴더 모양을 먼저 보여 주고, 「이 모양으로 만들까요?」 에 답하면 생성기 · 샘플 · 훅(파일을 쓰거나 명령을 돌리기 전후에 저절로 도는 검사)이 제자리에 들어갑니다.
파일을 쓰거나 명령을 돌릴 때 허용을 묻는 창이 뜹니다. 이 폴더 안 작업이면 허용하세요. 실수로 거부했으면 «다시 해줘» 라고 치시면 됩니다.
세션은 Step 3 에서 한 번만 새로 엽니다. Code 탭에서 새 세션을 열고 같은 폴더를 고릅니다. 그때 스킬 · 서브에이전트 · 훅이 함께 켜집니다.

쉬었다가 돌아오면 같은 폴더를 열고 `쿠팡 리포트 에이전트 실습 이어서` 라고 치세요.

`.claude` 폴더는 맥 Finder 에서 숨김 폴더라 안 보일 수 있습니다. `Command + Shift + .` 을 누르면 보입니다.

## 완성 예제 먼저 보기

완성예제를 로컬 웹으로 엽니다. Code 탭에서 이 `02 쿠팡 종합 리포트 에이전트/` 폴더를 열고 이렇게 치세요.

```text
완성예제/결과물 폴더를 python3 -m http.server 로 띄우고 2026-10-20_0702 폴더의 리포트를 브라우저로 열어줘
```

`http://localhost:8000/2026-10-20_0702/노을뷰티_광고리포트_2026-10-20.html` 처럼 주소가 열립니다. 다 보면 「로컬 웹 꺼줘」 라고 하세요.
실습 중에 만드는 리포트는 클로드가 로컬 웹 주소(`http://localhost:8770/…`)로 열고 그 주소를 화면에 보여 줍니다. 끄려면 `리포트 서버 꺼줘` 라고 하면 됩니다.

- 1회차 자료 (10/01~10/20) · 매출 7,910,030원 · 광고비 4,123,739원 · ROAS 191.8% (전체 매출 기준)
- 매출 1위 · 스칼프 샴푸 27.3%
- 인사이트 · 「광고 ROAS 191.8%로 적자 위험」 · 「후반기 매출 43.0% 성장」

## 여덟 단계

| 단계 | 하는 일 | 확인할 것 |
|---|---|---|
| Step 0 폴더 만들기와 준비 확인 | 만들 모양을 보여 주고 묻는다 · 생성기 · 샘플 · 훅 복사 · 설치 점검표 · 없는 부품은 묻고 설치 | 폴더 모양 · 「모두 있음 · 부품 준비됨」 |
| Step 1 입력 확인 | 가장 최근 날짜 폴더의 엑셀 4종 | 2026-10-20 · 파일 4개 |
| Step 2 CLAUDE.md 만들기 | 기준을 보여 주고 묻는다 (주문 변화 30% · 편중 70% · 적자 위험 ROAS 200% · 양호 300%) | 제목 4개 · 판단 기준 줄 |
| Step 3 스킬과 검토 서브에이전트 넣기 | coupang-report · 리포트검토 | 파일 2개 · 새 세션 (훅도 이때 켜진다) |
| Step 4 리포트와 검토 | 「광고 리포트 작성하자」 | 검토 통과 · 매출 7,910,030원 · `결과물/2026-10-20_…/` |
| Step 4-2 보고 고치기 | 리포트를 열어 보고 색 · 절 순서 · 요약 카드 · 차트 중 고칠 곳을 고른다. `report_template.py` 에 고쳐 다음 달에도 남긴다 | 새 결과물 폴더에 고친 모양 · 숫자 그대로 · 검토 다시 통과 |
| Step 5 3회 구동 | 자료만 바꾸고, CLAUDE.md 기준만 바꿔 다시 (매출 편중 70% → 50%) | 「주력 상품 매출 비중」 안내 → 「매출 편중 위험」 경고 · 결과물 폴더 3개 (4-2 를 했으면 4개) |
| Step 6 노션 발행 | 통합 키 · 페이지 ID(주소 끝 32자리) · 페이지 ··· > 연결 · `.env` 에 넣기 · 사람 승인 뒤 | 노션 페이지가 열린다 |
| Step 7 메신저 요약 | 슬랙 · 디스코드 중 고르고 웹훅 만들기 · 시험 메시지 · 요약을 먼저 보여 주고 승인 뒤 발송 | 팀 채널에 도착 |

**Step 2 CLAUDE.md 와 Step 4 검토 통과는 건너뛰지 마세요.** 기준 없이 만든 리포트와 검토 없는 리포트는 팀에 보낼 수 없습니다.

## 내 자료로 할 때

**꼭 필요한 것은 판매 2종**(셀러 인사이트 일별 판매 · 상품별 판매)입니다. **광고 보고서 2종은 있는 것만** 넣습니다. 없으면 리포트의 광고 숫자가 빠집니다.

### 내 쿠팡 파일 받는 순서

1. 셀러 인사이트 > 일별 판매, 셀러 인사이트 > 상품별 판매를 받습니다 (꼭 필요)
2. 광고센터 > 광고 보고서 > 매출 성장 광고 보고서, 신규 구매 고객 확보 광고 보고서를 받습니다 (있는 것만)
3. 네 파일 모두 **같은 기간 · 7일 이상**으로 고릅니다. 매출 성장 광고 보고서가 8일 이상이면 상품별 주문 변화까지 나옵니다
4. 매출 성장 광고 보고서는 **키워드 단위 · 일별**, 신규 구매 고객 확보 광고 보고서는 **일별**로 고릅니다
5. 파일 형식은 **.xlsx** 로 받습니다
6. `리포트 자료/{내 브랜드}/` 안에 폴더를 만듭니다. 폴더 이름은 **기간의 끝 날짜**입니다 (예 10/01~10/25 이면 `2026-10-25`)
7. 받은 파일을 **받은 이름 그대로** 그 폴더에 넣습니다. 파일 이름을 바꾸지 않습니다

## 자주 나오는 질문

**ROAS 가 1부 분석기와 다르게 나와요**
2부 리포트의 ROAS 는 **전체 매출 ÷ 광고비** 입니다. 1부 분석기는 광고 전환매출 ÷ 광고비입니다. 기준이 달라 숫자가 다릅니다. CLAUDE.md 「지표 계산법」 에 적혀 있습니다.

**노션이나 메신저가 없어도 되나요**
됩니다. Step 4 검토 통과까지가 최소선입니다. 노션과 메신저는 `.env` 에 키를 넣었을 때만 합니다.

**설치가 안 돼요**
- 맥에서 `brew` 를 찾을 수 없다 · Homebrew 가 없습니다. 클로드가 보여 주는 Homebrew 설치 한 줄을 터미널 앱에서 직접 칩니다. 맥 로그인 비밀번호도 거기서 넣습니다. 클로드는 비밀번호를 받지 않습니다
- 윈도우에서 `winget` 을 찾을 수 없다 · 마이크로소프트 스토어에서 «앱 설치 관리자» 를 먼저 설치합니다
- 설치했는데 명령을 못 찾는다 · PATH(명령을 찾는 자리 목록)는 새 세션부터 잡힙니다. Code 탭에서 새 세션을 열고 같은 폴더를 고른 뒤 `쿠팡 리포트 에이전트 실습 이어서` 라고 칩니다. 그래도 안 되면 데스크탑 앱을 껐다 켭니다
- 관리자 권한을 묻는다 · 승인 창에서 «예» 를 누릅니다. 회사 컴퓨터라 막혀 있으면 회사 IT 부서에 python 설치를 요청합니다

**기준을 바꾸려면 어디를 고치나요**
CLAUDE.md 「판단 기준」 줄만 고칩니다. 코드나 스킬은 고치지 않습니다.

**리포트 색이나 순서를 바꾸고 싶어요**
Step 4-2 에서 합니다. 결과물 html 이 아니라 `report_template.py` 를 고쳐야 다음 달 리포트에도 남습니다.
