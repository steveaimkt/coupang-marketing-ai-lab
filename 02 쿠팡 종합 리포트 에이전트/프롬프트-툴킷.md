# 프롬프트 툴킷 · 쿠팡 종합 리포트 에이전트

> **A 는 참고용**입니다. 강의 6·7교시에서 강사가 시연할 때 쓴 요청이고, 실습에서는 실습 스킬이 대신합니다.
> **B 는 실습에서 실제로 치는 한마디**입니다.

## A · 참고용 요청 예시 (강의 시연)

### A1 · CLAUDE.md 로 기준 잡기 (7교시)

```text
이 폴더의 CLAUDE.md 를 만들어줘. 제목은 나는 누구인가 · 지표 계산법 · 판단 기준 · 하지 않는 것 네 개로.
ROAS 는 전체 매출 ÷ 광고비, 일별 판매 맨 아래 합계 행은 빼고 세.
주문이 30% 넘게 변한 상품은 따로 빼고, 사람 확인 없이 노션이나 메신저로 보내지 마.
```

### A2 · 엑셀 4종으로 리포트 (6교시)

```text
리포트 자료/노을뷰티 의 가장 최근 날짜 폴더에 있는 엑셀 4종으로 리포트를 만들어줘.
광고 요약 · 지면 · 키워드 · 상품별 매출 · 취소 · 일별 추이를 표와 차트로 넣어줘.
```

### A3 · 원본으로 다시 세기 (7교시)

```text
리포트검토 서브에이전트로 방금 리포트를 원본 엑셀과 맞춰 봐줘. 파일은 고치지 말고 발견한 것만 알려줘.
```

### A4 · 노션과 메신저 (7교시)

```text
검토를 통과했으면 노션에 올려도 될지 먼저 물어봐줘. 올린 뒤에는 요약 다섯 줄을 보여 주고, 보내도 되는지 물어봐줘.
```

## B · 실습에서 치는 한마디 (8교시)

| 언제 | 한마디 |
|---|---|
| 처음 시작 (빈 폴더에 zip 만 넣고) | `이 폴더의 coupang-report-lab.zip 을 .claude/skills 에 풀고 쿠팡 리포트 에이전트 실습 시작` |
| Step 0 · 폴더 만들기 | `1` (이 모양으로 만든다) |
| Step 0 · 설치 | `설치` (점검표에 없음이 있을 때) |
| 설치 다시 점검 | `이 실습에 필요한 것 설치 점검표 다시 보여줘` |
| 쉬었다가 다시 · 새 세션 뒤 | `쿠팡 리포트 에이전트 실습 이어서` |
| Step 4 · 리포트 | `광고 리포트 작성하자` |
| Step 4-2 · 보고 고치기 | `리포트 맨 위에 인사이트를 먼저 보여줘. 생성기에 반영해서 다음 달에도 남게 해줘` |
| Step 4-2 · 색 | `리포트 머리 띠와 막대 색을 노을빛 주황으로 바꿔줘. report_template.py 에 반영해서 다시 만들어줘` |
| Step 5 · 2회차 (샘플) | `보관/2026-11-09 폴더를 리포트 자료/노을뷰티 안으로 옮기고 광고 리포트 작성하자` |
| Step 5 · 3회차 | `CLAUDE.md 의 매출 편중 기준을 50% 로 바꾸고 리포트를 다시 만들어줘` |
| Step 7 · 웹훅 만들기 | `슬랙 웹훅 만드는 법 알려줘` (슬랙 페이지를 열어 줍니다) · `디스코드 웹훅 만드는 법 알려줘` |
| Step 7 · .env 열기 | `.env 를 편집기로 열어줘` · 붙여 넣은 뒤 `웹훅 주소 제대로 들어갔는지 확인해줘` |
| Step 7 · 시험 발송 | `디스코드로 시험 메시지 보내줘` |
| Step 7 · 요약 보기 | `메신저 요약을 보내기 전에 먼저 보여줘` |
| 지난 리포트 보기 | `결과물 폴더에 쌓인 리포트를 로컬 웹 목록으로 보여줘` |
| 리포트 서버 끄기 | `리포트 서버 꺼줘` |
| 다음 주 | 새 날짜 폴더에 4종을 넣고 `광고 리포트 작성하자` |
