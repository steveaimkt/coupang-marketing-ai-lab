# [실습 파일] 브랜드 마케터를 위한 AI 기반 쿠팡 마케팅 실무

> 마소캠퍼스 VOD 과정의 실습 파일입니다. 클로드 데스크탑 앱의 Code 탭 하나로 진행합니다.
> 실습 자료는 모두 가상 뷰티 브랜드 「노을뷰티」 자료입니다. 실제 쿠팡 파일을 고쳐 만들었고, 상품명 · 캠페인명 · 검색어 · ID 는 모두 가짜로 바꿨습니다. 칸과 값 형식은 실제 쿠팡 파일과 같습니다.

## 챕터

| 폴더 | 교시 | 만드는 것 |
|---|---|---|
| `01 쿠팡 광고 분석기/` | 2~5교시 · 실습은 5교시 | 매출 성장 광고 보고서 → 6개 탭 광고 분석기 → 링크 |
| `02 쿠팡 종합 리포트 에이전트/` | 6~8교시 · 실습은 8교시 | 엑셀 4종 → 리포트 → 검토 → 노션 · 메신저 |

챕터마다 `README.md` 를 먼저 읽으세요. 시작하는 법과 완성 예제 여는 법이 있습니다.

## 공통 준비

1. 클로드 데스크탑 앱 설치 (claude.ai/download) · 유료 요금제로 로그인
2. 받은 실습 파일의 압축을 풉니다
3. 챕터 `README.md` 의 «시작하는 법» 대로 합니다. 이름을 마음대로 정한 **빈 폴더**를 만들고, 챕터의 zip(`coupang-ad-lab.zip` 또는 `coupang-report-lab.zip`)을 **압축을 풀지 않고** 그 폴더에 넣은 뒤, 데스크탑 앱 위쪽 **Code** 탭에서 그 폴더를 고릅니다
4. python · node 가 없으면 실습 Step 0 에서 클로드가 설치 명령(맥 터미널 · 윈도우 파워셸)을 보여 주고, 답을 받은 뒤 설치합니다

완성예제는 깃허브 리포 https://github.com/steveaimkt/coupang-marketing-ai-lab 에서도 볼 수 있습니다.

## 자료 넣는 규칙 (두 챕터 공통)

- 쿠팡에서 받은 파일은 **이름 그대로** 둡니다
- 날짜는 **폴더 이름**이 맡습니다. 리포트 마지막 날짜로 짓습니다 (예 `2026-10-20`)
- 분석은 이름이 가장 뒤인 날짜 폴더를 읽습니다. 지난 자료는 지난 폴더에 그대로 남습니다
